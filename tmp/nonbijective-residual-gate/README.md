## 今回の具体的な差

implicit-equation-gateでは残差全体の可逆写像Qを使い、Qの逆をかければ層を除けた。今回は

`Q(a,b) = (a+a(a+1)b, b+b(b+1)a) mod 2^w`

とする。Qはw>=2で非単射だが、Q(a,b)=(0,0)となるのはa=b=0だけ。出力z,t、元の処理f,gに対しa=z-f、b=t-gを代入し、展開した二つの式がゼロになる条件を保存する。全体の逆写像が存在しないことは前の案との差であるが、それだけでは新規性や解析耐性を支持しない。

**ゼロの保存**：a(a+1)とb(b+1)は偶数なので、Q mod2は(a,b)に一致する。Q=0ならa,bは偶数。するとQの成分に現れる係数1+(a+1)bと1+(b+1)aは奇数で、mod2^wで逆元を持つためa=b=0。

**非単射**：w>=2で(1,0)と(1,2^(w-1))はどちらも(1,0)へ写る。したがって、全入力に対する逆写像は作れない。これは零点集合の簡約が難しいという主張ではない。

## 復元器に渡したもの

factor_observer.pyは、展開済みの係数辞書、変数名、幅のみを受け取る。元のf,gや残差a,bは渡さない。因数分解で見つかった因子から、片方の出力について係数±1の一次式になっているものを候補とし、元処理との合同式比較は検証側で行った。入力はobservations.json、検証側の元係数と全候補はresults.json。

これはSymPyによる整数環上の因数分解であり、Z/(2^32)上の一般的な多項式分解ではない。大きな係数の積が折り返すと、整数の因数分解では元因子が見えなくなる場合がある。元の残差関係が失われたわけではないため、その不成功を方式の強さへ読み替えない。また、未知Wasmから式を抽出する処理は未実装。同じPythonプロセス内で関数を分けており、OS隔離ではない。
