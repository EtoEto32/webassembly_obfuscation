# 対応関係を持つ集合状態：算術試作

2026-10-12。新規性・解析への効果は未確認、採用保留。既知の数学的表現をそのまま新しいアルゴリズムと呼ばない。CSEC研究とは独立した設計検証であり、既存原稿には反映しない。

## 今回調べた具体的な差

以前の symmetric-state は同じ1変数関数で各要素を更新した。今回は2組 (a,b), (c,d) の**組内の対応関係**に計算が依存する。a,c と b,d を別々の集合にすると、どの値同士を掛けるかを失う。そのまま以前の試作の式を流用しては正しさを保てない。

状態は X=a+c, Y=b+d, P=ac, Q=bd, R=ad+cb の5値とする。以降の算術はmod 2^w。元の更新は各組について x'=x+y²+u, y'=y+x²。同じ古い状態から同時更新する。uは外部入力vに対し、(X XOR Y)の下位bitが1ならv、そうでなければv+1を選ぶ。この条件は組全体の交換で変わらず、係数から評価できる。

bx=X+Y²-2Q, by=Y+X²-2P とすると更新は次の通り。

```
X' = bx+2u
Y' = by
P' = P+YR-QX+Q²+u*bx+u²
Q' = Q+XR-PY+P²
R' = R+PX+QY+R²-2PQ+u*by
```

個別の a,b,c,d を更新時に抽出せず、5つの値で次状態を計算する。上式はそれぞれ更新後の和・積・交差積を展開して得た。除算を含まないので、整数上の恒等式が正しければmod 2^wへ移せる。現時点で証明支援系による形式証明は行っていない。生成器や任意Wasmの変換器でもなく、この特定の更新則の算術試作である。

## 実測

- 3bitの全4変数状態4,096通り×外部入力8通り：32,768更新、一致。
- 32bit境界値625件とseed 0x43524F53による2,048件：各8回、21,384更新、一致。
- 合計54,152更新で不一致0。32bitでは分岐の両側を通過した（20,040回と1,344回）。

参照実装は個別の組を更新し、その後で係数を計算する。比較側は上の5変数の式を直接更新する。係数の定義関数は初期化と参照側で共用しているため、完全に別々の実装系による二重検証とは言わない。

交差項を捨てる誤りも確認した。(0,0),(1,1)と(0,1),(1,0)は最初の4係数が一致するが、同じ外部入力に対する更新後の係数が異なる。具体値はresults.jsonのlost_correlationに保存した。

3bitでは係数状態は1,696通り。うち160通りには、単なる組の交換では一致しない複数の元の状態が入る。これは整数剰余環での衝突の観測であり、暗号学的安全性や解析困難性を示さない。互換な代表状態だけで将来出力を再現できるなら、元のラベルを復元できなくても解析者は目的を達成し得る。

## 新規性と次の採否条件

この表現はmultisymmetric polynomial（多重対称多項式）の既知の考え方に属する。検索ではBriandの論文に2組・2変数の整数係数生成系に関する記載が見つかった。全文取得は失敗しており、生成定理全体の仮定を読了したとは扱わない。少なくとも「多変数の対応関係を対称式で持つ」発想自体を独自と主張する根拠はない。

今回の式が既知の生成系の直接適用である以上、この試作だけを新アルゴリズムとして採用しない。別の具体的保護規則が得られない場合は、正しさが通っても棄却する。変数数や次数を増やしただけの候補を次々に作らない。

次に実施するなら、まず以下の限定した再構成試験を行う。解析者には5係数、幅、係数の意味を与え、元の4値や入力履歴は与えない。各bitを持ち上げて同じ5係数になる4値を1組探索する。成功は**任意の互換代表状態**の発見と、その後8更新での公開係数一致と定義する。元のラベルの復元とは区別する。1観測につき係数照合100,000回を上限とし、超過を安全性証明と扱わない。これは表現を既知とする強い観測者で、未知Wasmからの自動同定ではない。現時点ではこの再構成試験、Wasm化、実行性能測定は未実施。
