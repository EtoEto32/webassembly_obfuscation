# 暗黙的 ARX 方式の解析前提の確認

## 状態

新しい難読化方式の採用には至っていない。前回の非単射残差候補の棄却を受け、次候補の評価で抜けていた入出力関係の補間を確認した。本作業を新アルゴリズムの貢献として数えない。

## 一次資料

Biryukov, Lambin, Udovenko, Cryptanalysis of ARX-based White-box Implementations, TCHES 2023(3), 97–135, DOI 10.46586/tches.v2023.i3.97-135。

- PDF: https://orbilu.uni.lu/bitstream/10993/55609/1/Cryptanalysis_Whitebox_ARX.pdf
- 本文で確認した範囲: §5.4、§5.5、§6冒頭、§10。39ページ全文を取得したが、全節を精読したとは扱わない。
- 著者実装: https://github.com/cryptolu/implicit_ARX_whitebox_cryptanalysis
- 固定コミット: 2b6c2098aab87d2804aae1cd11a3ae3a0ba2ab90。
- README全文、decompose1quad.py の recover_quadratic_ANF を読んだ。他の取得コードは関数位置を検索した範囲に留まる。著者コードは実行していない。

論文では、内部ラウンドに問い合わせ、低次数の入出力関係を補間する。アフィン符号化された加算では双線形関係が利用できる。二次符号化への拡張と限界も述べる。したがって、表現式だけを複雑化しても、簡単な関係が入出力に残れば不十分である。一般の Wasm 全体を解析できるという主張ではない。次候補についても、内部処理を切り出して任意入力で呼び出せるかを明記する必要がある。

## 独立した小規模参照実験

relation_probe.py は標準 Python で作成した参照実装。著者の SageMath 実装の移植・完全再現ではない。

対象は、GF(2) 上のランダムな可逆アフィン写像で前後を符号化した整数加算の写像 (x,y) -> (x+y mod 2^w,y)。単項式基底は定数、入力ビット、出力ビット、入力ビット×出力ビット。観測者の nullspace に元の符号化係数は渡さず、問い合わせた組の評価行のみ渡す。

幅3・4ビット各3例を使い、全入力域から関係空間を求めた。すべての入力について、全出力候補を走査し関係を満たす候補を数えた。

| 幅 | 例数 | 各例の問い合わせ数 | 関係空間次元 | 出力が一意に定まる入力 |
|---|---:|---:|---:|---:|
| 3 | 3 | 64 | 18 | 各64/64 |
| 4 | 3 | 256 | 25 | 各256/256 |

合計960入力で一意の正しい出力が得られた。これは全域を使う小規模な実装検証であり、未知入力に対する汎化や大きな幅での少数問い合わせ復元を証明しない。小さい全域なら単純な参照表も可能なため、この結果に解析上の優位性や新規性は主張しない。鍵回復、非線形符号化の分解、Wasmからのラウンド抽出、性能測定は未実施。

再現には、空ディレクトリへ relation_probe.py をコピーして Python 3.12.14 で実行する。結果が既にある場合は上書きせず停止する。シード、全問い合わせ組、復元関係、生の候補数は probe-results.json。

## 次候補で要求する差

1. 実装の式の次数だけでなく、保護する関係そのものに残る低次数関係を調べる。
2. 内部関数に任意入力を与えられないという仮定だけで効果を作らない。白箱での実行切り出し、状態変更、スナップショットへの対応を説明する。
3. 単純なラウンド融合や高次数化は、それだけでは新方式として採用しない。既存の補間・分解との実質的な差を伴う変換規則が必要。

以上は設計条件であって、それを満たす新しいアルゴリズムの発見ではない。目標は未達成。CSEC原稿・既存実験は変更していない。
