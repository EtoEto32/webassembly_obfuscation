## 自分たちの候補の数式上の監査

以下は今回検討した案についての代数的検討。著者ツールの再現結果、既存論文への新しい攻撃の主張、実測結果ではない。

### M1：固定した左右の基底変換

R=Z/(2^32)、n>=2、固定されたdet(P)=det(Q)=1の行列を使い、

`A(x) = P diag(x,1,...,1) Q`

とすればdet(A(x))=x。復号せず表現上で更新する式も書ける。B=P diag(0,1,...,1) Qとすると加算はA(x)+A(y)-B、乗算はA(x) Q^{-1} P^{-1} A(y)。しかし、

`A(x) = B + x C`, `C = P e1 e1^T Q`

であり、各要素がxのアフィン式となる。行列サイズを増やしても、この具体化は多変数アフィン符号化から離れない。

さらに、同じP,Qを使ったA(0),A(1)を得られる観測条件なら、B=A(0)、C=A(1)-A(0)を得る。Pの第1列とQの第1行はmod2でそれぞれ非零なので、Cには奇数要素C_ijが存在する。この要素はRの単元であり、

`x = (A(x)_ij - B_ij) * inverse(C_ij) mod 2^32`

と復元できる。これは全xについての代数的説明で、乱数試験を代用した主張ではない。P,Qが変わる異なる観測同士に、この二点復元を無条件で適用してはいけない。生成ログを伏せた任意Wasmへの自動適用を実装したわけでもない。

判断：M1は採用しない。固定基底・次元を変えて再試作を増やさない。

### M2：任意行列に対する一回のrank-one加算更新

`det(A+u v^T)=det(A)+1` を任意の表現行列Aで成立させる案は、そのままでは不可能。A=0、n>=2ならuv^Tの全列は同じベクトルの倍数であり、行列式は0。目的の1にならない。

この反例は「任意行列」という条件を否定するもの。表現集合をdiag(x,I)の軌道などへ制限すればA=0を除外できるので、行列式符号化全体の不可能性証明ではない。合法状態を限定した新しい更新規則の可能性は、この反例だけでは決まらない。

判断：無制約のM2は採用しない。状態を限定するなら、その不変条件・初期化・保存・復元に要するコストを定義してから別途判断する。

### M3：SAS 2009の有理数構成をi32へ移す

先行例のtrace関係が保存される構成なら、行列式を計算せず `x=trace(A)-1` と読める。これ自体は本文の関係式から直ちに従い、新たな一般攻撃を発見したとは扱わない。

有理数で非零なら割れる値でもRでは偶数に逆元がない。単にb!=0という条件では移植できない。bを奇数にする等の修正やWasm化だけを新方式としない。

判断：この移植を新アルゴリズムとして採用しない。

## 残る課題

行列式そのもの、固定基底による混合、既存の数値表現への移植は新規性の根拠にならない。一方、すべての状態依存行列変換が既存手法と同じ、または無効だと証明したわけではない。もし継続するなら、固定アフィン表現や既知のtrace関係に還元されない具体的な合法状態集合と更新規則が必要。非線形化・次数増加だけでは十分でない。

新しい有望な規則を得る前に、この既知構成のWasm実装や大規模な性能測定は増やさない。今回追加したのは一次資料と数式上の採用・不採用の判断であり、生成Wasm・新規実験結果はない。元の研究目標は未達成のまま。CSEC原稿・以前の実験・保護設定は変更していない。
