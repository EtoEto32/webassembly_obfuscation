# Boolean lift of the finite-ring evaluator: applicability and limitation

2026-10-12. Mathematical applicability improved; novelty unresolved and no
algorithm adopted. This is a local SHA-256 T2 experiment, not a complete hash.

Follow-up: [weighted-contraction.md](weighted-contraction.md) constructs a
pairwise strict product-ultrametric contraction, compares the update with an
inspected residual-iteration source, and records a new independent pair check.
No new construction-level difference was established; further convergence
tests or a full-hash port of this unchanged rule are not the next action.

## Rule and all-input argument

First expand a fixed acyclic bit computation into gates. Represent each bit by
one coordinate of R=Z/(2^w), with external input coordinates fixed to 0 or 1.
Use integer polynomials AND(a,b)=ab, XOR(a,b)=a+b-2ab and OR(a,b)=a+b-ab.
They agree with Boolean gates on {0,1} and preserve all 2-adic congruences
even on non-Boolean intermediate values. Rotation becomes a permutation of
bit references, not a numerical shift of an unknown ring coordinate.

For the triangular polynomial gate map F, use the previously proposed rule

```
v_next = F(v) - 2A(v-F(v))  (mod 2^w).
```

The experiment uses A with A[i,i]=1 and A[i,(i+1) mod n]=1. It has feedback
across the topological order. All reads are from the old vector. The unique
fixed point is the Boolean gate evaluation r: I+2A is invertible, so a fixed
point satisfies v=F(v), whose solution is unique by topological induction.

Let d be the maximum number of gate layers. The precision argument in
convergence.md applies with d rather than the number of nodes: after each d
updates, one further bit of every coordinate agrees with r. Thus d*w updates
suffice from every initial v. This is a mathematical proof for the generated
polynomial DAG, not machine verification of its compiler or a full hash.

The original counterexample with a numerical right shift remains valid. The
lift changes the equation representation to meet the theorem's hypotheses;
it does not prove the original word-level rule works through arbitrary shifts.

## Concrete SHA expression and observed results

The implemented expression is the actual 32-bit SHA-256 round term

```
T2(a,b,c) = (ROTR2(a) XOR ROTR13(a) XOR ROTR22(a))
           + ((a AND b) XOR (a AND c) XOR (b AND c))  mod 2^32.
```

A ripple-carry addition and polynomial gates give 381 internal coordinates and
depth 67. `check_bitlift.py` compares against a separate word-level T2 formula.
The true root is used only by assertions, never to compute an update.

At ring widths 1,2,8,32, each of 17 word-input triples was run with an all-max
initial vector and a seeded arbitrary initial vector: **136 cases, zero
mismatches**. Every 67-step precision milestone and the final complete internal
vector were checked. Width 1 is an unmixed control because 2A vanishes there.
Results and script hash are in `bitlift-results.json`; Python 3.12.14.

These are not 136 messages or hash digests. No Wasm module, SHA block chaining,
padding, optimizer experiment or SMT run was added in this turn.

## Exact parity factor and consequence for novelty

Let rho reduce each ring coordinate modulo 2, and let F_B be the ordinary
Boolean gate map. At **every** state and every step,

```
rho(v_next) = rho(F(v)) = F_B(rho(v)).
```

The first equality holds because the mixing term has a factor 2. The second
holds because reducing the gate polynomials modulo 2 gives the corresponding
Boolean gates. This is a direct operation-level derivation for this generator,
not an assumption that all simulations are equivalent novelty-wise.

Consequently the low bits already give the full T2 result after 67 steps for
every width w. The remaining iterations up to 67*w erase the upper bits of
the auxiliary coordinates. Those bits can still be nonzero when the output
low bits are correct. A separate evaluator using Python's Boolean &, |, ^
checked the parity equality at every step: **15 runs, 67 steps each, 382,905
coordinate comparisons, zero mismatches**. Results are in
`parity-lift-results.json`, generated by `check_parity_lift.py`.

Later independent-review clarification, 2026-10-12: this describes a quotient
reader, not the actual `extract` implementation in `check_bitlift.py`.
That implementation shifts/adds complete words without `&1`, after the full
67*w settling period. Replacing its reader and stopping time gives a simpler
equivalent evaluator, but does not itself establish that the original generator
is a published construction. A complete Wasm hash experiment now exists at
`experiments/sha256-fixedpoint`; the older instruction below to defer that
implementation is superseded. Novelty is still unresolved.

This does not reject the candidate because a decoder is easy. It identifies
what the concrete construction changes: a Boolean circuit's synchronous
evaluation is lifted with upper-coordinate dynamics invisible to the parity
output. The current work has not identified an independent generation rule
beyond bit-circuit conversion, polynomial lifting and the earlier mixed
residual iteration. A new name or extra iteration count would not establish one.

## Closest prior comparison, bounded claims

Ranea, Vandersmissen and Preneel, *Implicit White-Box Implementations:
White-Boxing ARX Ciphers*, CRYPTO 2022, section 3, Definitions 3–4 and the
evaluation paragraph on PDF pages 7–9:
https://crypto.iacr.org/2022/papers/530630_1_En_2_Chapter_OnlinePDF.pdf

Their implementation evaluates quasilinear implicit functions: fixing the
input leaves an affine system in output unknowns, solved using Gaussian
elimination. Here fixed inputs still leave nonlinear products of unknown
intermediate coordinates, and execution uses a bounded synchronous iteration.
That is a concrete difference from that specified evaluator, not proof of
independence from all implicit methods or known nonlinear iterative solvers.

A search located Kelley's *Iterative Methods for Linear and Nonlinear Equations*
passage naming x_next=x-BF(x) preconditioned nonlinear Richardson iteration.
The full PDF fetch timed out; only the search-extracted passage was visible.
It is a relevant follow-up for the update form, not evidence that its real-space
convergence theorem proves this finite-ring, global d*w bound. Do not conflate
these scopes or claim the exact generator was found there.

## Corrected evaluation and next decision

The authorized independent reviewer found that the earlier README incorrectly
required resistance to a public inverse/tracing. That requirement was removed
from README.md and convergence.md. The reviewer also confirmed the bit-lift's
congruence preservation and the limited scope of the 136-case result; they did
not independently rerun it. Easy decoding remains irrelevant to adoption.

The applicability hole is closed for fixed Boolean DAGs, including rotation
wiring. The independent construction is still unestablished. Do not count
this local evaluator as the requested new hash obfuscator or repeat its tests
as though they settle novelty. A next comparison must address the whole
finite-convergence generation rule and the exact parity factor above before
expanding it to a new full-hash implementation. Overall goal remains active.
