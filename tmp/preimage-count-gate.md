# 出力を逆像の個数から取り出す案：具体構成は既知の計数保存SAT変換

## 1. 候補の変換規則

有限の非巡回Boolean回路Cの入力をx、内部ゲートと出力の変数をvとする。
各ゲートgの元の関数をop_g、出力変数をv_gとして、等式

    Phi_C(x,v) = AND_g [v_g <-> op_g(predecessors_g)]

を作る。入力xを固定し、出力ビットjの変数v_out,jを1に制約する。
変換後の評価器は

    F'_j(x) = #{v : Phi_C(x,v) AND v_out,j}

という解の個数を返す。全出力ビットに適用すれば元の語を構成できる。
言い換えると、各ゲートの不一致ビットと(1 XOR v_out,j)を並べた写像の
零の逆像の個数を計算する。探索空間を列挙すれば有限時間で実行可能。

意味保存の証明：回路のトポロジカル順序で、固定入力は各ゲートの値を
一意に決める。従ってPhi_Cの内部変数への充足割当はちょうど1個。
追加制約v_out,jによってそれが残るのはF_j(x)=1の場合だけである。
ゆえにF'_j(x)=F_j(x)は整数として等しい。これは有限個の入力によるテストからの推測ではない。

SHA-256へ適用するならChまたはMajの各ビットをこの評価器に置き換えられる。
ただし、これは適用方法の定義だけで、WasmやSHA全体への適用を実行した記録ではない。

## 2. 最小例と先行規則の操作対応

Ch(x,y,z)について、補助変数n,p,q,oを導入する。

    n <-> NOT x
    p <-> x AND y
    q <-> n AND z
    o <-> p OR q
    o = 1

最初の4式を満たす割当は固定入力ごとに唯一。最後の式を加えた解の個数は
x=0ならz、x=1ならyなのでChに一致する。各同値式をCNFへ変換しても、
同値を両方向に強制し、不要な自由変数を導入しなければこの数は保存される。
片方向の含意に置き換えた単なる充足可能性保存では、同じ主張はできない。

|候補の操作|先行の一般規則との対応|
|---|---|
|各演算へ補助変数を導入|回路の各ゲートへ変数を割り当てるTseitin変換|
|元の入力を固定|テンプレートCNFへの入力リテラルの付加|
|対象出力を1へ制約|出力リテラルの付加|
|解の個数を返す|一意拡張・計数保存性から0または1を取得|
|SHAの語を再構成|上の同一規則を32ビットに適用|

この構成では新しい生成規則や意味保存機構が残らない。
解の個数を取ること自体は、既存の計数保存変換の直接の利用になる。

## 3. 一次資料と確認範囲

[Semenov et al., Translation of Algorithmic Descriptions of Discrete Functions
to SAT with Applications to Cryptanalysis Problems, LMCS 16(1), 2020](https://lmcs.episciences.org/6177/pdf)
の§2を確認。ゲートごとのCNFを結合する式(2.4)、Theorem 2.4と直後の説明は、
アルゴリズムからSATへの変換と逆像・解の個数の対応を扱う。
§3冒頭はTransalgでこの種の変換を実装する説明。
本候補への操作対応と固定入力ごとの一意性証明は上の直接導出である。

論文は暗号解析のための逆像探索を主眼とする。本候補と同じWasm難読化を
提案しているとは主張しない。しかし、元の回路をゲート制約へ写し、
出力を制約して解の数を見るという数学的構成は既存規則の特殊例である。
用途を難読化へ変更するだけでは現行目標のLevel 1/2の根拠にならない。
