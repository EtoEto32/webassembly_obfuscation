# 非一意な値表現の設計監査と復元による棄却試験

2026-10-12。独立研究の技術記録。新規アルゴリズムの採用報告ではない。CSEC原稿は変更しない。

## 一次資料で確認した範囲

- Stephen Drape, *Obfuscation of Abstract Data-Types*, Oxford博士論文、2004、§3.2–3.2.3、本文48–51頁。https://www.cs.ox.ac.uk/files/2892/thesis.pdf 。本文確認。抽象化関数と不変条件による意味保存、複数の具体状態が同じ抽象状態を表す場合、処理前後の関数の可換条件を扱う。したがって「同じ値に複数の内部表現を持たせる」ことを新規原理としない。本試験の二次式やWasm実装がこの論文に掲載されているという主張ではない。著者実装は未実行。

## 今回、実装前に定めた棄却条件

非線形な冗長表現を追加しても、入口の既知入力と観測した状態から小さな式が得られ、その式で反復中の全状態を復元できるなら、この具体案は採用しない。単なる二次式の導入や実行中の表現更新を新規性とはしない。

## 試作した具体的な規則

すべての算術はmod 2^32。元の通常計算は、入力x,yに対してn&31回、次を反復する。

```
c = xが奇数なら3、偶数なら5
x' = x*x + c*x + y
```

値xを二つのi32値a,bで表す。初期値はb=mask, a=x-b*b。復元関数はD(a,b)=a+b*b。同じxに2^32通りの表現がある。

```
t = b*b
b' = rotl(b,7) XOR a
c = (a+b)が奇数なら3、偶数なら5
a' = a*a + 2*a*t + t*t + c*(a+t) + y - b'*b'
```

D(a',b')=(a+b*b)^2+c*(a+b*b)+yである。bとb*bの偶奇は等しいため分岐も一致する。この代数関係と固定の反復上限から、この算術モデルの意味保存を説明できる。有限個の入力によるテストの一致を全Wasmプログラムの証明とはしない。

これは専用WATを生成する試作であり、任意の既存Wasmを変換するコンパイラではない。命令はi32算術、分岐、ループ、ローカル変数、観測用import。メモリ、例外、参照、暗号処理は対象外。観測コールバックの例外や環境依存動作は対象外で、記録するだけのコールバックを使う。

## 復元者に与えた情報

`recover.cjs`は独立した子プロセス。生成器をimportせず、WAT、復元関数、元ソース、内部状態の正解を読まない。与えるのは16件の公開入力xと入口の二つの観測値だけ。係数-2..2、基底1,a,b,a²,ab,b²の15,625式を列挙する。

ただしこれはブラックボックス入出力だけの攻撃ではない。内部の二値を入口で同時に観測でき、その二つを以降も追跡できる、強い観測条件である。二次式という探索文法を設計者が選んだ、方式を知る解析者の限定試験。未知の一般バイナリから観測箇所・変数を自動発見する評価ではない。

候補Wasmには入口と各反復後のobserve(a,b)を明示的に入れ、raw/O2両方で残す。通常版はobserve(x,0)。この計測が最適化を制約するため、計測のない版への結果の一般化や実行速度の優劣を主張しない。

## 実測結果

通常版・冗長表現版それぞれraw/O2、計4本を生成。各1,060入力（36境界組と1,024乱数組）、各17,190状態を独立したBigIntの元の計算と照合し、不一致0。反復数0/1/2/31、上限で折り返す32、0xffffffff、符号境界を含む。乱数seedは0x38abcdef。

冗長表現版raw/O2のどちらも、16件から係数[0,1,0,0,0,1]を探索範囲内で一意に復元した。つまりD=a+b²。学習に使っていない1,060入力の途中状態17,190個すべてでも一致した。BigInt側の照合器は復元した係数を使うが、期待値は元のスカラー計算から独立に求める。

探索時間は単発でraw約8.24ms、O2約5.18ms。反復した性能測定ではなく、環境間比較や最適化の優位性の根拠にしない。処理速度・オーバーヘッド測定は棄却条件成立のため未実施。近接既存方式との完全な4条件比較も未実施で、この候補の有効性を示したとは報告しない。

## 判断

**この具体案は棄却する。** 複数表現、非線形化、反復中の表現更新を組み合わせても、小さい固定復元式が残る。非線形でデータ依存分岐を持つ元の計算でも、その内部表現の復元はこの試験では容易だった。一般の非一意符号化の無効性を示す結果ではない。

次の候補には、少なくとも固定の低次数復元式が簡単に露出する今回の原因への具体的な対処が必要。ただし次数・係数・変数を増やしただけの案を新方式としない。既存の領域別表現にも戻らない。具体的な異なる変換操作と近接方式を特定してから次の実装に進む。本試験を新規アルゴリズムの完成や、別の評価研究への目標変更として扱わない。

## 再現

Node.jsで`experiment.cjs`を実行する。WABT/Binaryenのインストールルートを環境変数WASM_TOOLS_ROOTで指定可能。既定は既存workspaceの.toolsを読み取り利用する。使用版はartifacts/results.jsonに記録。CSECのコード・データを編集しない。

主要成果物：experiment.cjs（生成・独立検証）、recover.cjs（観測値だけからの式探索）、artifacts/inputs.json（全入力）、artifacts/results.json（環境・SHA-256・結果）、各wasmとwat、*.training.json、*.recovery.json、*.observations.json（全観測値）。
