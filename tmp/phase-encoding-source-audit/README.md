## 4. 検討した二つの規則

候補A: E_iを256bit状態の任意の全単射、D_i=E_i^-1とする。元のラウンドT_i,wに対し

```text
U_i,w = E_(i+1) ○ T_i,w ○ E_i^-1
```

と定義すれば、任意の入力列について中間のE_i^-1○E_iが消え、入口E_0と出口E_n^-1で元の計算へ戻る。前回の共通Dを仮定しないため、259bit下界とは矛盾しない。ただしU_i,wは依然としてiに依存する。共通U_wにしたければ、すべてのi,wで右辺が同一になるという**追加条件**を満たす必要がある。相殺だけではカウンタ除去を保証しない。ここが今回明示した設計上の不足である。

候補B: 中央演算Fを変えず、全単射A,BがB○F○A=Fを満たすように選ぶ。周辺の層へA,Bを合成して、Fを挟む符号化・復号を省く。この自己同値条件による意味保存は既知の構成原理である。SHAの演算をFに選ぶことだけでは独立した発明にならない。

いずれも固定幅の純粋な写像としての仕様。メモリ、trap、入出力エンディアンを含むWasmプログラム変換は未定義。定義式にE_i^-1が書けることは、低コストに生成・実行できることを保証しない。

本文確認資料: Ranea and Preneel, [On Self-Equivalence Encodings in White-Box Implementations, SAC20 preproceedings](https://sacworkshop.org/SAC20/files/preproceedings/02-WhiteBox.pdf)。§3定義4–5の入出力符号化と隣接境界の逆写像、§4定義7の自己同値による内部符号化の相殺、§5定理1の前提、§6冒頭の攻撃モデルを確認した。全文の証明検証・著者コードの実行はしていない。

| 項目 | 候補A | 候補B |
| --- | --- | --- |
| 数学的原理 | 隣接逆写像の相殺。定義4–5と対応 | B○F○A=F。定義7と対応 |
| 表現 | 境界ごとのE_i | 演算の自己同値に制約した表現 |

| 依存関係 | ラウンドごとに符号化を変更 | 中央演算を介して符号化を相殺 |
| 困難性の根拠 | E_i不明というだけでは不足 | 対称性の存在だけでは不足 |
| 適用差分 | SHA/Wasmへの変更のみでは新規性なし | SHA演算への変更のみでは新規性なし |

論文の対象はSPN暗号と特定の符号化クラスであり、任意のSHA実装を攻撃した結果ではない。定理1は小さい**置換**の並列結合を前提にする。SHAのCh/Majは3語から1語への関数なので、そのままこの前提へ入れられない。SHAのmod2^32加算をGF(2)上のアフィン層として扱うこともできない。したがって「この論文が存在するのでSHA共同符号化はすべて解ける」とは判定しない。

検索で見つかった *On Recovering Affine Encodings in White-Box Implementations* の https://eprint.iacr.org/2019/096.pdf は取得エラー。本文確認済みと扱わない。検索結果中のその他の論文・サイトも今回の結論の根拠にはしていない。

新規性判定は、上記二つの**抽象的な説明だけ**では既存研究との差分にならない、という範囲に限定する。既知の一般的枠組みに表現できるすべての具体的アルゴリズムが新規性を持たないという主張ではない。
