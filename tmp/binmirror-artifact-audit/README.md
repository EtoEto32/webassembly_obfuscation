# BinMirror 配布成果物の適用条件

## 1. 状態
Inconclusive。2026-10-12。新規難読化方式は未確立で、研究目標は継続中。この調査は攻撃用比較対象の適否を判断する静的監査である。

## 2. 達成事項
論文がリンクする配布ZIPを取得し、公開MD5と一致を確認した。独自の読み取り専用スクリプトで1885エントリを列挙し、9ファイルのソースを保存、コアPython 25ファイルを文字列検索した。著者コードをimport・実行していない。

## 3. 未達成事項
新規変換規則、汎用Wasm変換器、提案方式のSHA-256、解析上の優位性は未達成。BinMirrorの論文実験も再現していない。

## 4. アルゴリズム
今回発明した難読化アルゴリズムはない。既知の解析器の修理や移植を新規方式へ数えない。

## 5. 先行研究・ソース照合
一次本文: [arXiv:2608.20628v1](https://arxiv.org/html/2608.20628v1)、§IV、付録Dを追加確認。実行記録からスライスを作り、観測に合うコードを合成・検査する手法。全入力同値の証明ではない。本文の新しい確認範囲は以前の導入部だけの記録とは区別する。

## 6. 再利用分類
tmp/contextual-invariant-recoveryの導入部調査はC（関連研究の参考）として再利用。新たに得たZIPも現状ではC。Wasm対応と検証器の妥当性が確認できるまでA（そのまま比較に再利用可能）にはしない。全コードが無価値だという判定ではない。

## 7. 実装・確認結果
audit.pyはZIPハッシュ、保存/参照フィールド、テスト関数のASTを検査しresults.jsonを生成した。Python 3.12.14で終了コード0。初回ダウンロードはsandboxのソケット制限で失敗し、許可されたネットワーク取得で成功。初回画面出力はcp932で失敗したためUTF-8へ変更して読み直した。これらを攻撃結果へ含めない。

## 8. 攻撃・比較結果
攻撃未実行。採用判断は「この固定版を無修正のWasm比較器にしない」。未対応・例外・欠損メタデータは解析耐性の成功件数へ入れない。著者モデルへのAPI呼び出しも行っていない。

## 9. 性能・サイズ・最適化
測定なし。ZIPの7802203 bytesは配布容量であり、難読化オーバーヘッドではない。

## 10. 判断の変更
以前は本文導入部だけを確認していた。今回は実装を調べ、比較への直接投入を見送る具体的根拠を得た。今後の候補で、実行中断や対応外を利用して強度を主張しない。BinMirror修理へ探索予算を移すこともしない。次に優先すべき未達成事項は、既存の符号化・等価書き換えと差分のある具体的変換規則の確立である。

## 11. Before/After
新しい変換を実装していないため今回のBefore/Afterはない。既存のSHA-256・MBAベースラインを変更していない。source-textは著者コードの閲覧用コピーで、難読化後コードではない。
