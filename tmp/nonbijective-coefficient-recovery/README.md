# 非単射残差候補の係数抽出による棄却

## 結論

候補 `nonbijective-residual-gate` の全8例（小係数4、大係数4）から、元の2出力を係数単位で正確に復元した。前回の整数因数分解で未解決だった大係数4例も復元できる。この候補の具体的な変換を採用しない。新しい難読化アルゴリズムを確立した成果ではない。

## 復元の根拠

環 R = Z/(2^w)Z 上で、入力 x,y の多項式 f,g と出力変数 z,t を考える。

    a = z-f(x,y), b = t-g(x,y)
    Q1 = a + a(a+1)b
    Q2 = b + b(b+1)a

Q1 の z^2 t^0 の係数（R[x,y] の元）は -g、Q2 の z^0 t^2 の係数は -f である。このため各係数を射影し、符号を反転すれば元の関係を直接取り出せる。整数因数分解、逆写像、元のソース係数、入出力問い合わせは不要。係数の mod 2^w による折り返しもこの恒等式を妨げない。

この恒等式は x,y の多項式 f,g に対して成立する。8例の実験だけを一般化した主張ではなく、出力変数に関する展開に基づく代数的説明である。ただし他の変換形や、変数混合・式の別表現まで解く主張ではない。

## 実験と観測者

観測者 observer.py に渡すのは前回保存した observations.json の各ペイロードのみ。変換の式族と変数順序を知り、展開済みの疎多項式を取得できる観測者である。Wasm バイナリからの自動式抽出、未知の方式の識別、一般的な剰余環因数分解は実装していない。

check.py は別に元の results.json の source_coefficients を読み、復元した f,g の係数辞書と照合する。この情報を観測者へ渡していない。これはコード上の情報分離であり OS の隔離ではない。

- 8例中8例で両出力の全係数が一致。
- 各例に境界値7種類の直積49組と固定シードのランダム2048組。
- 合計16,776入力組、出力不一致0。
- Python 3.12.14、標準ライブラリのみ。シードと入出力のハッシュは results.json に保存。
- 実行速度、難読化オーバーヘッド、バイナリサイズはこの早期棄却実験では測っていない。

再現: 新しい空ディレクトリに observer.py と check.py をコピーし、Python で以下を実行する。既存結果への上書きは禁止している。

    python check.py C:/Users/ettotto/Documents/wasm-structured-encoding/candidates/nonbijective-residual-gate

## 次の設計に残る条件

非単射で逆写像がないことは、必要な零点関係を抽出できないことを意味しない。次候補は高次の出力変数の係数から元の関係が直接露出する設計を避ける必要がある。ただしこの必要条件を満たすだけでは新規性や解析耐性は確立しない。新しい候補を立てた場合も、最も近い既存方式との差と、より簡単な復元を先に確認する。

本記録は新規性調査の代わりではなく、既存候補に残っていた未解決例を閉じた棄却記録である。CSEC 原稿・既存実験は変更しない。
