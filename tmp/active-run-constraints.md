# 現在の実行制約（過去の停止残量を更新）

更新日2026-10-12。ユーザーの最新の直接指示: 「残り使用量が30%になったらいったんやめてほしい。結果をそこそこ出してほしい」。

- 停止目安は残量30%。以前の残量10%条件を置き換える。使用30%ではない。
- 利用枠を定期的に確認する。残量30%以下になったら新しい実験を開始せず、進行中の処理を安全に区切る。コード・結果・再開手順を保存し、ユーザーの条件付き停止指示に従ってゴールをpausedにして報告する。未達の目標をcompleteにしない。
- 枠の値を取得できない場合は残量を推測しない。
- 今回確認できたCodex primaryのusedPercentは14、残量86%。アカウント全体で共有する枠であり、この研究だけの消費率ではない。
- 残量までは、候補の設計・実装と採用・不採用の判断を判断できる比較結果を優先する。単なる件数の水増しや調査記録だけを完成としない。肯定的な結果・新規性を保証したり捏造したりしない。
- 研究目標、独立リポジトリ、CSEC原稿を変更しないこと、論文を作らないこと、ローカルの通常計算のみという範囲は維持する。
