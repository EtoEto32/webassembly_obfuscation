# 次候補の設計条件：原状態の復元と計算の理解を区別する

2026-10-12。新しい候補の採用ではなく、保存済み実験と一次資料に基づく設計判断。研究目標は新規アルゴリズムの開発のまま、未達成。

## 今回確定した判断

1. **多対一の状態表現を増やす方向は、そのままでは継続しない。** correlated-recoveryでは32bitの2,673観測中2,549件で互換な状態を再構成し、うち2,004件は元の状態の組交換とも異なった。それでも後続8更新の係数出力が一致した。原状態が一意でないという数学的性質だけでは、計算を理解・再利用する解析を妨げていない。残る124件は探索予算による未解決であり、その部分を選んで強い方式と報告しない。
2. **単に式を大きくするe-graph生成器の改良を、新しいアルゴリズムとして採用しない。** SaMBAの本文と実装が直接の比較対象になった。さらにScramblerにも式サイズや時間などの終了条件を持つ等価式生成が記載されている。有限の抽出条件を足すだけでは、既存研究との差を立証できない。
3. **観測条件を弱く変えて成功を作らない。** 既知の表現から復元できた結果は保持する。未知バイナリからその表現を同定する追加コストは別に測定できるが、同定器をまだ実装していないことを新しい保護規則の証拠にしない。

## 次に必要な具体的な設計成果

次候補はまず、入力のIR上のどの操作をどの操作列へ変えるのかを示す。新規性の主張は、表現の名前や未測定のデータセットではなく、その書き換え規則、成立条件、従来の規則では残っていた依存がどう変わるかに置く。

保護対象は、解析者が理解・再利用できる簡潔な計算表現とする。特定の原変数名や消えた履歴を復元できないだけでは成功にしない。一方で、等価なプログラムの存在だけをもって自動的に弱いと判定することもしない。元のコード自身が等価プログラムなので、問題は実際の再構成に必要な情報と作業量である。

候補を実装する前に、通常版と近接方式にも同じ解析を適用できる成功条件を固定する。対象式が未対応、解析がpanic、生成器が停止、といった事象は独立した失敗分類にする。特定の構造にだけ対応する自作復元器ならその範囲を記す。一般的な強度の結論にはしない。

現時点ではこの条件を満たす次の具体的な規則を確定できていない。ここを埋めることが残っており、文献整理や既存生成器の修理をゴールの成果へ置き換えない。外部情報やユーザー入力がなければ一切進めない状況ではないため、ゴールをブロック状態にはしない。

## ScramblerをSaMBA修正案との比較に追加

Seoksu Lee, Sangjun An, Eun-Sun Cho, *Scrambler: Mixed Boolean Arithmetic Obfuscation Tool Using E-graph and Equality Expansion*, arXiv:2603.03624v2, 2026-03-06。一次本文 https://arxiv.org/html/2603.03624v2 、§3–5を確認。式のサイズ、探索条件、時間等の終了条件を伴うe-graphベースの生成を説明する。著者実装はこの確認では実行していない。SaMBAの負コスト抽出と同一の実装・停止挙動だとは主張しない。また、構造指標の増加をこちらで実証した解析耐性へ読み替えない。

この資料は以前の合成候補でも確認済みだったが、今回のSaMBA停止問題を踏まえ、**有界な式生成への修理そのものを新規候補として復活させない**という判断に接続した。検索語：Scrambler obfuscation 2026 paper / data obfuscation open problems program / obfuscation future work nonlinear encoding。その他の検索結果を全文確認済み資料として使っていない。
