## 継承する基準

- distorted-interpreter-audit：解析器を意識した生成自体は既存。
- decoder-feedback-gate：復元器が成功する候補群の除外は、一般的な競合学習・含意一般化だけでは新方式にならない。
- contextual-invariant-recovery：到達不能状態で局所式が異なることと、実行中の意味を復元できないことを混同しない。
- observational-quotient-gate：不要な内部状態を消すだけで、プログラム理解を難しくしたことにはならない。

## 合成問題として固定するもの

論理状態x、公開入力u、元の遷移T(x,u)を固定する。候補thetaは初期化E、状態更新U、終了時の出力処理F、およびそれらを実装する命令列を含む。生成器だけが持つ抽象化関係R(x,z)は、解析器の教師入力とは分ける。ただし解析器には生成されたプログラム全体を渡すため、E/U/Fに残った復号処理を隠さない。

保護対象は「元の更新処理を簡潔な計算として再構成する費用」であり、公開入出力や不必要な内部状態の秘匿ではない。内部値の復元は、その再構成を助ける否定試験の一つと位置付ける。内部値が復元できないという結果だけで採用しない。

最初の正しさ条件は通常の帰納的refinement：

1. 全初期入力に対してR(x,E(x))。
2. R(x,z)なら、全許可入力uに対してR(T(x,u),U(z,u))。
3. 実行可能な終了地点で出力処理が元の出力と一致。

この3項は既存の方法であり、新しいアルゴリズムの差分ではない。メモリ・trap・外部呼出しが入る場合は出力条件を拡張する。最初から対応済みとはしない。

## 復元失敗の証人に課す条件

固定した復元器dに対し、単に `存在z: d(z) != D(z)` を満たす候補を作ってはいけない。zが実行不能なら、意味のある否定例にならない。

候補に対する反例は、具体的な初期入力と有限入力列を含める。元の実行と候補の実行を同時にたどり、対象地点に到達することを確かめる。その命令列の全観測値Oを使って、`d(O) != x` を確認する。既存の不変条件I(z)が真というだけでは、到達可能性の証明に置き換えない。

探索の有限化で長さhまでに制限した場合、次を区別する：

- 有効な具体的反例が見つかった：その復元器が全実行で正しいという主張は否定できる。
- 反例が見つからない：長さh以下の範囲でのみ一致。全実行で復元できる証明ではない。
- 有限状態の正確な到達閉包を全数検査した：そのモデルの全到達状態について判断できる。
- SMTがunknown／timeout：判断不能。候補の効果として数えない。

復元器dから候補群Cをまとめて除外するなら、各候補の実到達領域に対してdが正しいという証明が要る。候補ごとに到達領域が変わるため、ある候補の観測集合を別候補へ無検証で流用しない。過大近似上で全称的に一致を証明することは十分条件になるが、過大近似から得た不一致は具体的到達証人で検証する。
