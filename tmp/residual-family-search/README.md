# 零点保存残差族の探索と非単元係数による復元

## 結果

96生成例（係数列として92種類）を試したが、採用候補は残らなかった。65例は両出力を係数の線形結合だけで復元でき、残る31例も係数から合計最大2ビットを除いて復元できた。最大4通りの零点確認で全体を決定でき、32ビット値1,536組の照合はすべて一致した。新規性や強度があるアルゴリズムの完成を意味しない。

この探索は前のnonbijective-residual-gateを係数・次数だけ変更した族であり、各生成例を新アルゴリズムとは呼ばない。小さな族の棄却実験である。すべての残差方式や暗黙関数方式の無効性も主張しない。

## 調べた規則と意味

mod 2^wで未知の元の値F,Gと出力候補z,tについて

    a = z-F, b = t-G
    Q1 = a + a(a+1)b R1(a,b)
    Q2 = b + b(b+1)a R2(a,b)

R1,R2の全次数上限を0,1,2とし、各32例を固定乱数で生成。係数は0..15、R2(1,0)は奇数に調整した。上限次数なので最高次係数が0になる場合もある。

Q=(0,0)ならmod2でa=b=0、従ってa,bは偶数となる。Q1のaに掛かる因子とQ2のbに掛かる因子はいずれも奇数の単元なので、a=b=0。逆方向も明らかであり、唯一の零点は元の値(F,G)である。w>=2では残差(1,0)と(1,2^(w-1))が同じ像(1,0)を持つ。この族は非単射でありながら唯一の零点を持つ。これは代数的説明であり、Wasm全体の正しさの証明ではない。

小幅w=3で各64残差を全列挙し、唯一の零点を照合。衝突はw=2,3,8,16,32で各例確認した。

## 解析者と成功条件

解析者はQの方式、R1/R2、変数の役割を知り、展開済みQ1,Q2のz,tに関する係数を取得できる。元F,Gを知る必要はない。係数を形式変数F,Gの多項式として記述し、係数の定数線形結合がFまたはGになるか、mod 2^32の線形系を解く。

完全なF,Gで解けない場合、2^v Fまたは2^v Gの係数恒等式を探す。その恒等式を公開係数へ適用するとF/Gの下位32-vビットが判明する。未確定の上位ビットを列挙し、公開されたQの零点であるかを確認する。元F,Gをこの零点確認へ渡さず、照合側のみが期待値と比較する。単一プロセス内の情報分離であり、盲検・OS隔離ではない。

| F/Gの未確定上位ビット数 | 生成例数 | 確認する候補数の上限 |
|---|---:|---:|
| 0 / 0 | 65 | 1 |
| 0 / 1 | 25 | 2 |
| 1 / 0 | 3 | 2 |
| 1 / 1 | 3 | 4 |

全例で各16組の固定乱数F,Gを検証。すべて一意に正しく復元できた。これは値ごとの復元であり、任意バイナリからの式抽出や元ソーステキストの復元ではない。恒等式はF,Gを形式変数として扱うため、F=f(x,y),G=g(x,y)への代入にも成立するが、バイナリから当該係数を取得する作業は別に必要。

## 独立検証

- search.py: 標準Pythonによる疎多項式展開と2進付値を使う剰余環線形系。
- verify.py: 同じQをSymPyで別に展開し、完全復元できた158個の出力別証拠を係数単位で確認。ソルバーの成功/失敗はmod4の全2×2行列・右辺4,096ケースで総当たり解と比較して一致。
- partial_recovery.py: SymPyで作った係数行列から偶数倍の復元証拠を求め、全96例で上位ビット候補を検査。証拠、期待値、復元値はpartial-results.jsonに保存。

今回、一般的な暗黙式ソルバー、Wasmの生成、性能・命令数比較は実装していない。低コストの係数復元で候補が残らなかったため、大規模実装へ進めない。古い因数分解が失敗したことだけで強度を認めなかった結果である。

## 再現

Python 3.12.14、SymPy 1.13.3。空ディレクトリに3スクリプトをコピーする。

1. `python search.py`
2. `RESIDUAL_CAS_PATH`をSymPyの導入先へ設定し、`python verify.py`
3. 同設定で`python partial_recovery.py`
