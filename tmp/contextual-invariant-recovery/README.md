# K1の具体化：観測状態からの不変条件復元

2026-10-12。新方式の採用結果ではない。contextual-invariant-auditのK1を具体化し、局所式の非同値性と実到達状態での難しさを区別した。前回の作業は状況報告のみで実験の進捗なし。今回の作業は新たに実行した復元試験と証明を保存した。

## 変換と判定

32bit環で補助状態 b=a²+c*a+d を維持し、通常の計算 e=(a XOR u)+a*u を e+((a XOR u) OR 1)*(b-a²-c*a-d) に置き換える。次の反復では a'=rotl32(a,5) XOR u、b'=a'²+c*a'+d。初期状態と更新で関係が成立する。純粋でtrapしない演算だけを対象とする。

これはK1の具体的な反証用モデルで、汎用Wasm変換器・Wasmバイナリ実行試験ではない。実用ハッシュや外部通信を扱わない。新たな難読化の効果は未確立。

事前の棄却条件は、到達状態の単純な関係を復元して追加項を消せること。候補はc,d=(1,0),(3,7),(5,11)の3設定。この3設定を別アルゴリズムとは数えない。

## 解析者に与えた情報

復元関数mineへ渡すのは16組の匿名2列の入口状態だけ。c,dや正解のaを教師ラベルとして渡さない。探索する関係は b+k2*a²+k1*a+k0=0。k2,k1は-8..8、k0は-16..16、bの係数は1と固定する。既知の候補に合わせた限定文法であり、未知のバイナリ全般に対する攻撃ではない。列の取得・対応付けは既知で、バイナリからの変数発見を実装していない。

その後の消去検証は復元した関係からbを代入し、32bit多項式を正確に正規化する。式やプログラム意味の取得を含む自動難読化解除器ではない。

## 実測と証明

- 3設定とも探索範囲内で関係が1個に定まった。すべての可能な関係に対する一意性ではない。
- 設定ごとに未学習128入力列×32反復、合計12,288状態で、復元関係と通常版／変換版の出力が一致。
- 設定ごとに、入口での成立、更新による保存、復元関係による挿入項消去をZ3 4.13.3で検査し、9件すべてunsat。各問い合わせはi32の純粋式に対するもの。入口・保存から任意の有限反復の関係が帰納的に従う。
- 一方、a=u=0,b=d+1という到達不能状態では元の式0・変換式1。この局所非同値性を難読化の強さとは扱わない。

check.py内の証明は、代入・多項式正規化後の式に対する検査である。未処理の巨大なSMT式を短時間で解けたという性能主張ではない。補助状態の更新自体が関係を直接記述しているため、静的解析でも容易な可能性がある。そこは実測していない。

結論：この具体化は棄却。係数や次数を増やすだけの再試作はしない。任意の文脈依存難読化が無効だという結論でもない。A2-MBAの未読本文との同一性を確定したとも扱わない。採用可能な新アルゴリズムの確立は依然として未完了。

## 再現・記録

Python 3.12.14、Z3 4.13.3、seed 0x4b31494e。WASM_SYNTH_DEPENDENCIESにz3パッケージ親ディレクトリを指定して `python check.py` を実行。結果はresults.jsonに保存するため、再実行時はコピーを使う。初回はsandbox内でz3.BitVecsを解決できず停止し、同じスクリプトを許可されたローカル実行で再実行した。ネットワークアクセスなし。

results.jsonには全学習状態、未学習状態、出力、復元係数、検査結果、時間、環境を保存。入力WasmはないためバイナリSHAを捏造しない。inventory.jsonは保存ファイルのSHA-256を記録する。
