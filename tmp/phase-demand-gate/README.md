# 後続処理に応じた非単射表現：採用前の確認

2026-10-12。新規アルゴリズムは未採用。これは設計上の条件と先行例を確認する記録であり、Wasm難読化器の完成ではない。

## 候補の規則

実行位置 p ごとに、以降に必要な観測だけを保つ射影 q_p を選ぶ。元の状態を完全に復元する関数は要求しない。遷移 F の前後で q_next(F(s,u)) = G(q_p(s),u) を満たす G を生成し、公開出力を保存することを目指す。前提は、同じ q_p に写る状態が、許されるすべての後続入力で区別されないこと。分岐条件がまだ未来の入力である場合、測定時に通った片方の経路だけでこの条件を判断できない。

これは具体的な新しい G の生成規則をまだ与えていない。通常の観測同値・不要情報除去と異なる保護機構を伴わないため、この枠組みだけを新しいアルゴリズムとして採用しない。

## 有限例で確認する条件

8bit状態 x の下位または上位4bitを未来の入力 b で選び、その値 n から (n + 2n² + u) mod 16 を返す。u は 0..15。既知の b に応じて x を4bitに射影してから演算する版と、元の8bit状態の参照版を独立の式で全件比較する。

- b 判明後は16同値類へ縮約できる。
- b 判明前は両方の後続処理を保存する必要があり、256同値類になる。
- 片方の射影を先に適用すると、同じ表現なのに未来の出力が異なる反例が生じる。

これは8bitの有限プログラムに対する全入力での検証であり、任意Wasmやi32変換の証明ではない。状態削減ができても解析が難しくなったとは言えない。元の全状態を復元できないことを成功条件にすると、不要情報を捨てる通常の最適化まで成功と数えてしまう。

## 結果と判断

8,192入力の出力比較で不一致0。分岐未確定では256同値類、確定後はどちらの分岐も16同値類だった。下位だけを先に残す案は x=0 と16、上位だけなら x=0 と1で破れる。どちらも捨てた側を選ぶ未来の分岐と u=0 に対し、元の出力は0と3になる。

この例の多項式 h(n)=n+2n² は、h(a)-h(b)=(a-b)(1+2(a+b)) で第2因子が奇数なので、mod 16上の全単射である。従って各半分の値は後続出力で区別でき、両方の未来の分岐を許すなら元の256状態のどの2つも同一視できない。これは本例の代数的説明であって、一般プログラムの不可能性定理ではない。

実測値と反例、全同値類は results.json。check.py が再生成する。既存 observational-quotient-gate は反復機械全体を対象にしていた。今回は後から入力される分岐条件と射影を行う時点の関係だけを調べたもので、過去の試験の追加標本として合算しない。

この単独案は見送る。非単射表現全般の不可能性も、未設計の具体的な規則の既知性も示していない。次の候補には、既存の符号化・最小化という枠組みのほかに、実際に解析対象の依存関係を変える規則が必要。その規則を式または擬似コードで示せるまで、名称や表現の変更を別候補として量産しない。
