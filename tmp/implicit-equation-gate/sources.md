# Primary-source audit

Search date: 2026-10-12. Search absence is not a novelty claim. No upstream implementation was run in this gate.

1. Ranea, Vandersmissen, Preneel, **Implicit White-Box Implementations: White-Boxing ARX Ciphers**, CRYPTO 2022. https://crypto.iacr.org/2022/papers/530630_1_En_2_Chapter_OnlinePDF.pdf . Read definitions 3–4, section 3.1, selected sections 5.1 and 6 passages. Framework uses implicit functions affine in output coordinates, permitting linear solving; affine output encodings preserve this property. Thus implicit evaluation and graph transformations are established. Nonlinear output equations alone are a difference from this condition, not demonstrated novelty/security. Author repository README inspected: https://github.com/ranea/whiteboxarx ; source not audited or run.

2. Barbu et al., **ECDSA White-Box Implementations: Attacks and Designs from CHES 2021 Challenge**, TCHES 2022(4), DOI 10.46586/tches.v2022.i4.527-552. https://pure.tue.nl/ws/portalfiles/portal/301659006/TCHES2022_4_19.pdf . Read abstract and section 5.1 definitions/lemma, section 5 opening. Extends implicit representation to finite fields, uses affine encodings and extra variables/equations. Finite-field statements are not automatically statements about the ring Z/(2^32).

3. **EP2831797B1, Securing accessible systems using dynamic data mangling**. https://patents.google.com/patent/EP2831797B1/en . Read textual portions of sections 2.3.6, C3, C16–C18 and Newton-method passages. Dynamic permutation polynomials and bit-by-bit inverse computations are already disclosed. Some displayed equations are images and were not inspected; no exhaustive patent comparison or legal assessment is claimed. The exact two-variable Q used in this gate is not asserted identical to a patent example.

4. Asghar, Galbraith, Russello, **Obfuscation through simplicity**, author manuscript dated July 19, 2016. https://www.math.auckland.ac.nz/~sgal018/simplicity.pdf . Read sections 2, 4 and 5.1. Algebraic branch merging is existing work; hiding the original CFG differs from preventing semantic understanding. This source does not establish novelty of residual mixing.
