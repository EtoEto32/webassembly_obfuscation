# SHA-224の最終出力切り詰めを途中へ移す案

2026-10-12。更新：実装した最終ラウンドの明示式は、操作ごとの生成手順が
既知の恒等式・寄与の移動・不要出力の除去で尽くされるため、Level 3として不採用。
experiments/sha224-erasure/novelty-decision.md に判断と導出を保存した。
同じWATが既刊だという主張ではない。以下は当初の採用保留時の検討記録。

## 1. 具体的な規則と正当性

SHA-224の最後のブロックだけを対象にする。最終出力は8語のうち先頭7語。
フィードフォワード用のBとスケジュールWを固定する。境界i以後のラウンドの
合成をR_iとする。各ラウンドは可逆なのでR_iも可逆。
Pは8語目だけを零にする射影で、piは先頭7語を取り出す写像とする。

    A_i = R_i^-1 o P o R_i

を境界iの状態へ適用してから元の残りの計算を行うと、

    pi(B+R_i(A_i(S))) = pi(B+P(R_i(S))) = pi(B+R_i(S))

となり、SHA-224出力は変わらない。加算はワードごとmod 2^32であり、
捨てた8語目から他の語への桁上がりはない。
A_iは非単射かつ冪等。これは可逆な状態符号化とは異なる数学的性質だが、
それだけで独立した新規性を認定しない。

R_i=R_(i+1) o T_iよりT_i o A_i=A_(i+1) o T_i。
従って複数境界で同じ射影を移した操作を挿入しても、射影の冪等性で一つに
まとめられる。大量に挿入すること自体は別の原理にならない。

## 2. 最終ラウンド直前の明示式

状態S=(a,b,c,d,e,f,g,h)について、次を同時代入する。

    g_new = 0
    h_new = h + ((NOT e) AND g) mod 2^32

他の6語は保持する。Ch(e,f,g)=(e AND f) OR ((NOT e) AND g)の
二項はビットが重ならないため、整数和としても等しい。
従ってh_new+Ch(e,f,0)=h+Ch(e,f,g)となり、ラウンドのT1が保持される。
T2も不変なので、次状態のa..gはすべて元と同じ。次状態hだけが零になる。
これはA_63=T_63^-1 P T_63の明示形である。

同時代入が必要で、gを消した後に古いgを使わずhを補正する実装は誤り。
また、この変更を最終ブロック以外へ入れると、捨てた8語目が次ブロックへ
渡るため同じ証明は使えない。SHA-256へそのまま適用しても出力を保存しない。

## 3. 先行研究と採否

[NIST FIPS 180-4](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf)
§6.2.2–6.3を基礎とする。上の射影の移動と明示式は直接導出。

[Sana Mehmood Awan, Security Through Obscurity: Layout Obfuscation of
Digital Integrated Circuits Using Don't Care Conditions, 修士論文, 2015](https://api.drum.lib.umd.edu/server/api/core/bitstreams/657e8237-3944-4b82-a73f-d8a52c4b8b59/content)
の要旨と§5.1（本文91–93頁、PDF105–107頁）を確認した。
出力へ伝わらない条件を利用して内部の機能を変える難読化の先行例である。
今回のSHAの射影式が同論文に載っているという意味ではない。

特に今回のg,hは相関させて変更する。個別の信号が単独でdon't-careに
なるとみなしてはならない。観測関係を

    C_i(S,Z) <=> pi(B+R_i(Z))=pi(B+R_i(S))

と置くと、A_iはこの関係の許容する代表状態を選ぶ構成である。
これは候補の意味保存の分類であり、任意の代表選択法が既刊という証拠ではない。
複数出力ノードの自由度をBoolean relationsで扱う先行資料として
[Savoj, Berkeley ERL-92-122](https://digicoll.lib.berkeley.edu/nanna/record/133904/files/ERL-92-122.pdf?registerDownload=1&version=1&withMetadata=0&withWatermark=0)
の検索結果に関連する記述があったが、今回の作業では本文未確認。
そのアルゴリズムと今回の生成手順が同一だとはまだ判定しない。
取得を試みたが、nanna配信URLはcache miss、通常のPDF URLは403だった。
関連するSavoj/Brayton ICCAD 1991のCiteSeer配信も403で、本文確認済みに数えない。
これはその資料の取得制限であり、研究全体の環境ブロックではない。

現在の明示例は、既知のCh式の和を保持して最後の不要語を消す短い書き換えで
説明できる。これだけを新しい原理として採用する根拠はない。
一般形のR_i^-1 P R_iについても、可逆な接尾計算を用いることを超える
独立した生成規則の差分をまだ提示できていない。採用は保留する。
情報を消す全方式の不可能性や、同じ生成器の先行発明を主張しない。

## 4. 実装と検証の範囲

- 追記（2026-10-12）：experiments/sha224-erasure/ に最終ラウンドの明示式を
  実装。通常SHA-224と変更版の実際のWasmが各531入力でOpenSSL SHA-224と一致。
  内部の最終8語目は全531例で変化した。補正なし版は531例、全ブロック適用版は
  473例で不一致を検出。詳細・全域の代数的証明・適用条件は同ディレクトリREADME。
- 既存SHA-256の入力バイト列だけを再利用し、SHA-224の期待値は独立に計算した。
- SMT・機械証明は行っていない。有限試験と代数的証明を区別する。
- 独立した構成の差分が得られる前に、全ラウンドへ射影を挿入する実装はしない。

再検討に必要なのは、相関した状態変更を扱う既知の観測関係に対し、
この生成手順のどこに独立した差分があるかという比較。
最後の不要な語を消す、射影を繰り返す、境界を変えるだけでは差分にならない。
全体の研究目標は未達成であり、この案を完成成果に数えない。
