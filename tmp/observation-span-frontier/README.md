## 具体的な削減規則

同じ入力領域上の純粋で全域的な式P,Qを考える。入力・定数・すべての途中値の各ビットを、入力に対するブール関数として扱う。そのGF(2)線形包をL(P)とする。

出力が等しく、cost(P)<=cost(Q)、L(P) subseteq L(Q)なら、Pを残してQを捨てる。

この規則は前回の「観測関数の集合包含」より強い削減が可能。ただし対象モデルは異なる。今回の復元者は観測ビットの多項式を使い、積の次数に上限があり、XOR項数は制限しない。**前回の演算数制限付き復元者に、そのままこの規則を適用してはならない。** 線形代数自体や一般の非支配候補保持を発明したという主張ではない。

理由: Pの観測関数はQの観測関数の線形結合に置換できる。次数d以下の多項式に代入して展開しても次数はd以下なので、Pで復元可能な対象はQでも復元可能。XOR項数や実際の探索時間は増える可能性があり、それらを保存する保証はない。

同じ純粋な式文脈に同じ出力を渡すと、穴の外で追加される観測関数は同じ。その共通集合を双方に追加しても線形包の包含は保存される。従ってこの限定モデルでは後続合成に対して安全な削減になる。副作用、共有DAG、分岐、ループ、trap、到達領域の変更、JIT後の値への拡張は未証明。
