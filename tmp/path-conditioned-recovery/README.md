# 経路に応じた二次表現：状態分類による復元と棄却

2026-10-12。独立研究の実装・比較記録。採用候補、論文ではない。前回の作業は遅延補正の先行例と判断を保存した進捗あり。今回の作業は固定式の復元失敗を誤って強度と扱わないため、具体案を比較実装して反証した。

## 結論

今回のdynamic-quadraticは採用しない。復元式の探索範囲を先頭二変数に限ると失敗するが、観測された0/1値で分類するだけで、入口の32組から二つの復元式を得られた。学習に含めなかった途中状態も全件一致した。単なる動的選択や非線形化を新規原理とはしない。

設計と事前の判定条件はprotocol.md。コードはexperiment.cjs、復元者は別プロセスのrecover.cjs。元バイナリを変換する汎用コンパイラではなく、同一の専用計算を4種類のWATとして生成する試作である。

## 設計上の差と先行例

前回の固定表現x=a+b²に対し、候補はx=a+(-1)^h*b²、hは入力に由来する分岐で更新する。対照は通常版、x=a+(-1)^h*bの自作動的線形版、hによる切替を除いた固定二次版。

US20190188157A1（2019-06-20公開）の本文では、実行時の符号化選択とtag間の再符号化が扱われる。https://patents.google.com/patent/US20190188157A1/en 。今回の動的線形対照は著者実装の再現ではない。実行時に選び直すことを新しい原理としない。本具体式の全先行例を調べ尽くしたとの主張もしない。新規性を支持する具体的な差分は現在ない。

## 正しさ

4種類×観測あり/なし×raw/O2の16本を生成した。各1,132入力（境界値108組と乱数1,024組）をBigIntによる元の計算と比較し、全出力が一致。観測版8本はそれぞれ17,778状態の抽象値も一致。動的版では8,365回のhの切替を観測した。

演算はmod2^32の加減乗算、回転、分岐、上限31回のループ。初期a=x-t、更新a'=a²+2at+t²+c(a+t)+y-t'から、a'+t'=(a+t)²+c(a+t)+yが成り立つ。有限試験に加えてこの代数関係が意味保存の説明になる。メモリやtrap、実用ハッシュ、任意のWasmへの適用は扱っていない。

## 復元結果

|版|先頭二変数の固定二次式|状態分類後の式|未学習状態の一致 raw / O2|
|---|---|---|---|
|動的線形|探索範囲内で0個|h=0: a+b、h=1: a-b|17,778 / 17,778|
|動的二次（候補）|探索範囲内で0個|h=0: a+b²、h=1: a-b²|17,778 / 17,778|
|固定二次（切替なし）|a+b²が一意|分類不要|17,778 / 17,778|

raw/O2ごとにそれぞれ全17,778状態が一致した、という表である。元ソースの復元ではなく、内部の元スカラー値の復元。復元者に与えたのは公開入力xと入口の匿名3状態だけ。状態の位置を見つける処理は実装せず、観測importで取得した。探索文法も方式既知の限定文法であり、未知の一般バイナリへ自動適用できる攻撃ではない。

特に「固定復元式がなくなった」とは言えない。全三変数を見れば、候補にも固定三次式 D(a,b,h)=a+b²-2hb² がある。二変数の二次式しか探さない評価器の失敗を耐性と誤認する例だった。

また、今回の元の計算では奇数cに対してx²+cxが偶数になるため、最初の更新以降のxの偶奇はyで決まる。この計算は非線形だが、分岐履歴の複雑さを代表しない。復元試験は入口で学び各群の不変な式を使うため、この単純さに依存した攻撃ではないが、実用的な経路難読化の評価には使わない。

## コストの探索的測定

観測importを含まない別バイナリで、同一の131,072呼出しを7ラウンド測定。各呼出しは15または16反復。JS/Wasm境界コスト込み。固定ウォームアップ後、実行順を乱数で変更。全バッチの出力checksumは通常版と一致した。

|版|O2サイズ byte|O2命令数|O2時間中央値 ms|最小–最大 ms|通常版比|
|---|---:|---:|---:|---:|---:|
|通常|88|31|2.698|2.673–4.139|1.00|
|動的線形|184|88|5.583|5.475–7.188|2.07|
|動的二次|208|104|5.954|5.884–6.503|2.21|
|固定二次|146|67|4.898|4.780–5.646|1.82|

命令数はWABT逆アセンブルでlocal宣言を除いた静的命令（end等を含む）。時間は1サンプル数msと短く、JIT・スケジューリングの影響が残る。線形版と二次版の僅かな差やraw/O2間の順位に意味を付けない。候補の採否は復元成功に基づき、この予備的コスト測定に基づかない。生の56測定はartifacts/timings.jsonに保存。精密な性能評価や汎用エンジン間比較は未実施。

観測版が最適化を制約する点から、解析成功をそのまま無計測版の完全な自動解除と同一視しない。一方、観測できる解析者に対する候補の目標はこの試験で達成できなかった。

## 再現と証拠

Node.jsでexperiment.cjsを実行する。WASM_TOOLS_ROOT省略時は既存workspaceの.toolsを読み取り利用する。Node v24.15.0、V8 13.6.233.17-node.48、WABT1.0.42、Binaryen133、Windows x64、Intel i9-11900K。乱数seed 0x741ac382。CPU設定・電力状態は統制していない。

- artifacts/results.json: 環境、16バイナリのSHA-256、サイズ、命令数、正しさ、復元結果
- artifacts/inputs.json: 学習・評価入力全件
- artifacts/*.wat, *.wasm, *.disassembly.txt: 入力と生成結果
- artifacts/*.training.json, *.recovery.json: 独立プロセスに渡した情報と復元式
- artifacts/*.observations.json: 出力と観測状態の全件
- artifacts/timings.json: 全測定と集計

再実行は同じartifactsに書くため、保存結果を保つ場合はこのディレクトリを別名へコピーしてから実行する。
