# 実行前に定義した比較・棄却条件

2026-10-12。既存の固定二次表現を受けた、動的表現の候補選別用試験。新規性の確定前に実施する。一般のWasm変換器ではなく専用WAT生成器。

計算はx'=x*x+c*x+y mod2^32、cは現在のxが奇数なら3、偶数なら5、反復n&31。対象はi32、分岐、有限ループのみ。メモリ、外部通信、マイニング、保護機能変更なし。

比較はplain、dynamic-linear（既存の動的符号化の発想に沿う自作対照）、dynamic-quadratic（今回の具体案）、fixed-quadratic（表現切替を除いた版）。dynamic-linearは著者コードでも特許実装の再現でもない。

値の意味はx=a+t。fixed-quadraticのt=b²。dynamic-linearのt=(-1)^h*b。dynamic-quadraticのt=(-1)^h*b²。初期b=mask、動的版h=mask&1、a=x-t。動的版は各反復でh'=h XOR (x&1)。b'=rotl(b,7) XOR a。a'は(a+t)^2+c(a+t)+yを展開し、新しいt'を引く。すべてmod2^32。b²とbと-bの偶奇は同じなので、xの偶奇はa+bから求められる。h'が履歴に依存するが、実行状態として保持される。

意味保存は上記の展開式と有限ループにより説明する。BigIntによる元スカラー計算との照合は別に実施し、有限個の入力によるテストと代数説明を区別する。

脅威モデル: 入口と反復境界の三つの内部値を同期して観測可能な解析者。観測場所の自動発見は含まない。元のソース・生成器・復号式は復元プロセスへ渡さない。ただし探索文法は設計者が選ぶ方式既知の限定試験で、完全ブラックボックスではない。

復元者は32個の公開入口値と匿名状態だけから、(1)先頭二変数の二次多項式、(2)観測された0/1変数で状態を分類した各群の二次多項式、を探索する。係数は-2..2。16個ずつの群を含める。入口の学習とは別の境界・ランダム入力を用い、全途中状態の復元を独立した元の計算と照合する。

棄却条件: 固定式の探索失敗が状態分類だけで解消し、未知入力の内部値も全件復元できるなら、今回の具体案を採用しない。探索文法の外の不在は証明しない。分類後に失敗してもそれだけで強度・新規性を認めない。

raw/O2の双方を確認する。観測importは最適化を制約するため、観測版の解析結果と、importなし版のコストを分ける。観測なし版も出力を検証する。性能は同一呼出し条件、固定ウォームアップ、順序をシャッフルした7ラウンド、各131072呼出し。中央値・最小・最大を記録。JS境界コスト込みの一環境の試験であり一般化しない。
