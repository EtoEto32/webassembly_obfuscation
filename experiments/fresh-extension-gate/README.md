# 独立入力の追加後も復元空間の比較を保つための条件

## 1. 状態：Inconclusive

2026-10-12。新規難読化方式は採用しておらず、研究目標の状態はactive（継続中）である。今回の成果は、合成規則が成立する範囲を確定するための補助的な結果であり、難読化変換や解析上の優位性を確立したものではない。

## 2. 達成事項

以前のquadratic-context-gateでは、単独では二次復元空間が等しい候補でも、後続処理を加えると違いが生じる例を示した。今回は、任意の共通観測を追加しても次数dの復元空間の包含関係が保たれる条件を特定した。独立した公開ブール入力を追加できるモデルでは、線形包の包含は十分条件であるだけでなく、必要条件でもある。

この必要条件から、包含関係がない任意の候補対について、独立入力d−1個で両者を区別する診断対象を作る手順を得た。既存の線形包の規則を超えて候補を削減する汎用の空間比較規則は、この保証を保ったままでは作れない。結論は、以下の定義と追加できる入力の条件に限られる。

## 4. 定義・条件・証明

従来の入力の同一領域X上で、O_P,O_Qをすべての観測ビットのブール関数の有限集合とする。定数1を加えたGF(2)線形包をL_P,L_Qとする。B_d(O)はOと1から高々d個を掛けた関数の線形包（d>=1）。観測の個数とXOR項数は無制限、積の次数だけを制限する。観測は全入力、すべての途中値、出力を含む。

独立した公開ビットr1,...,r(d−1)を追加し、領域をX×{0,1}^(d−1)へ広げる。従来の関数はrによらない。Rをこれら各ビットの集合とする。追加時にその積を計算して観測へ加えることはしない。

**命題：B_d(O_P ∪ R) ⊆ B_d(O_Q ∪ R) ⇔ L_P ⊆ L_Q。**

十分性：Pの各観測をQの線形結合へ代入しても、高々d個の積の次数は増えない。これはR以外の共通観測Hについても成立し、Hが従来の入力に依存していてもよい。

必要性：L_Pに属しL_Qに属さないfを選ぶ。T=f*r1*...*r(d−1)はPで次数d以下で表せる。仮にQでも表せるとする。新たな入力の平方自由ANFでr1*...*r(d−1)の係数を取る。その係数はTではf。一方Qの各次数d以下の単項式では、新たな入力d−1個を含むため従来の観測は高々1個しか残らない。従って係数はL_Qに属する。線形結合後も同じで、fがL_Qにないことに矛盾する。d=1では新たな入力0個、元の線形包比較そのものになる。

ブール関数の新たな入力に関するANFの一意性と、係数の線形抽出だけを使う代数的証明。機械定理証明器は使用していない。fが複数観測のXORでもPの次数はd以下であり、単一観測に限定する必要はない。

したがって、任意の共通観測を追加しても包含関係が保たれることは、線形包の包含関係と同値である。ただし、出力が同じ純粋式を文脈に埋め込み、その外側で共通の観測が追加される場合を想定している。共有状態・副作用・制御フローを持つ任意のWasm文脈について、完全抽象性を証明したものではない。既存の入力領域を拡大できない閉じた合成問題には、必要条件をそのまま適用できない。
