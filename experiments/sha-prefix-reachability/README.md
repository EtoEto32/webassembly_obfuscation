# SHA-256の8ラウンド状態への到達入力の構成

## 1. 状態：Inconclusive

2026-10-12。新規難読化原理と比較上の優位性は未達。研究目標の状態はactive（継続中）。本実験は、到達可能状態の制約を利用する候補を選別するための補助成果であり、新しい難読化アルゴリズムとして採用しない。

## 2. 達成事項

SHA-256の固定IVから、指定した任意の8語の作業状態へラウンド0〜7の8回で到達する32バイトメッセージの構成式を導出した。282個の指定状態に対し入力を生成し、既存の完全SHA-256 Wasmに観測用storeだけを加え、raw/O2双方で実行確認した。

この境界で、全32バイト入力に対して常に成り立つ述語P(a,b,c,d,e,f,g,h)は、全256ビット状態で真でなければならない。したがって「この8語には到達しない組合せがある」ことだけに基づく変換・opaque predicateはここでは成立しない。これは以下の全称構成による結論であり、282ケースのサンプリングだけからの推測ではない。

## 3. 未達事項

独立した難読化原理、再利用可能な新方式の変換器、そのSHA全体への適用、攻撃上の優位性、実行コストの公平な比較は未達。SHA全体を実行した事実は、新方式の適用に成功したという意味ではない。

## 4. 構成式と証明

語は32ビット、加減算はmodulo 2^32。Q(a,b,c)=Σ0(a)+Maj(a,b,c)。通常のラウンド前状態をs=(a,b,c,d,e,f,g,h)、ラウンド定数をKiとする。

目標s*から8語pを順に作る：

```text
p[0:4] = s*[0:4]
p[j+4] = s*[j+4] - p[j] + Q(p[j+1],p[j+2],p[j+3])  (j=0..3)
desired_A[i] = p[7-i]  (i=0..7)
```

固定IVから通常状態を追跡し、各ラウンドで次を選ぶ：

```text
Wi = desired_A[i] - Q(a,b,c) - h - Σ1(e) - Ch(e,f,g) - Ki
```

すると更新後aはdesired_A[i]になる。8回後のaの履歴はpである。通常ラウンド式から、aの履歴pに対応するe,f,g,hは

```text
e[j] = p[j] + p[j+4] - Q(p[j+1],p[j+2],p[j+3])  (j=0..3)
```

なので、8回後の全8語がs*に一致する。pを求める式は三角形で一意、Wiも既知の前状態とdesired_Aから一意。よって固定IVに対するW0..W7と8回後の状態の対応は全単射である。IVの値に依存しない導出だが、本実行検証のIVは標準SHA-256のみ。

Wiをbig-endianで連結した32バイトを入力とする。正規パディングはW8以降に入り、W0..W7を変えない。そのため自由に選んだu列だけの実験と異なり、実際の有効な入力による到達証拠になる。全称部分は代数的証明であり、機械検証済み定理やSMT証明ではない。
