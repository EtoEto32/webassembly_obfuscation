# 保存済みCoBRA出力と置換ASTの32ビット等価性検証

1. **状態: Inconclusive（研究全体の目標継続）**。既存比較基盤の未実施だった局所SMT検証を行った。新規な難読化原理と優位性は未確立。

2. **達成事項**。2026-10-12、保存済み11件のCoBRA返却式、6箇所のWAT置換AST、以前未実行だったMBA式を検証。全18件の不一致クエリにZ3がunsatを返した。既知の式や重複する置換を含み、18個の異なる新定理ではない。

3. **未達事項**。新規変換器・新方式のSHA適用・公平な比較での優位性は依然不足。局所式を検証したことは、SHAプログラム全体の形式証明、メモリ・制御・paddingの正しさの証明ではない。

4. **検証した規則と意味**。QF_BV、全変数32ビット。各式の差が存在するかを問う。i32のadd/sub/mulはmod 2^32、論理演算はワード単位。右shiftは論理右shift、シフト量は31とのANDでWasmのmod32規則を表す。constは下位32ビット。返却式は制限したPython ASTからSMTへ、置換記録はWAT ASTから直接SMTへ変換する。任意Pythonコードをevalしない。未知命令は拒否する。

   対象は純粋なlocal.get/constとこれらの演算。局所変数の値は無制約のため、到達状態に限定した検証ではない。一方、保存されたASTと実バイナリの対応全体をこのSMTスクリプトが証明するわけではない。

5. **先行研究・新規性**。新しい数学的変換は導入していない。CoBRAの保存結果と既知MBAを検証したもの。今回のための追加文献検索は行っていない。生成SMTとソルバーの結果は、原研究の全アルゴリズムの正しさや安全性を保証しない。
