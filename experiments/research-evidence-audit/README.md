## 4. 発明したアルゴリズムと技術的原理

発明の成果として採用・報告できるアルゴリズムはない。下表は検討と反証の経緯をたどるための参照先であり、手法の数を示すものでも、新規アルゴリズムの一覧でもない。

| 保存先 | 規則・設計 | 棄却/未採用の理由 |
|---|---|---|
| [表現3案](../representation-gate-20261012/README.md) | 統計量依存回転、carry差分、結合状態 | 簡単な逆変換、情報喪失、既存座標変換の問題 |
| [テンソル基底](../tensor-support-gate/README.md) | 各Boolean wireを2成分へ写す | 公開DAGから有限支持と小ゲートを復元 |
| [奇数倍率修正](../tensor-quotient-gate/README.md) | テンソル状態の具体値を増やす | mod2への射影で倍率が消え、元の小回路が残る |
| [積への詰め込み](../packed-product-gate/README.md) | ビット演算を整数積の係数へ移す | 詰め方により衝突または抽出失敗。carry-free版の独立性も不足 |
| [共通反復](../common-iteration-gate/README.md) | 一つの遷移を回数で使い分ける | 固定回数では可換性、可変回数では限定モデルの実行回数下界 |
| [因数表現](../divisor-carrier-gate/README.md) | ブール値を互いに素なatomの積へ写す | 選択入力とGCDで因数分解せず復元。倍率修正も除去可能 |
| [群表現](../group-order-gate/README.md) | 剰余加算を群演算へ写す | 正確な全単射準同型は2冪位数を強制し、既知のbit liftingで復元 |
| [表現と更新の探索](../joint-transition-search/README.md) | 復号式を固定しない有限共役探索 | 小モデルではすべての表を伝播で回復。独立した原理は未成立 |
| [幅変更](../joint-transition-search/LIFT-AUDIT.md) | 上記表を具体式へ整理し幅を変更 | 多くに反例。残る8例は通常の反転・交換・定数オフセット |

## 7. 実装と検証の結果

[SHA比較基盤](../sha256-research-baseline/README.md) は、padding・全64round・block chaining・digest出力を含むWasmを持つ。単なる圧縮関数ではない。plain/MBA×raw/O2/O3の6本、各531入力の検査が保存されている。

直前の [外部CoBRA接続](../sha256-cobra-check/README.md) では、6バイナリから同じ規則で選んだ24式（重複を除く11種類）を解析し、全11出力を有限検査した。返された2種類の簡約則をWasmへ反映し、全6本を再アセンブルして531入力ずつ実行した。

これらの実行は各報告の時点の事実である。今回の監査はその保存コード・バイナリ・入力・出力記録の対応を確認した。局所SMTファイルが存在しても未実行なら証明済みとしない。

## 8. 攻撃実験と既存方式との比較結果

CoBRAは既存MBA加算を通常の加算へ簡約した。plain rawのアドレス式からゼロ加算を消す結果もあり、「簡約箇所数=難読化除去数」ではない。O3には対象外の木が残り、プログラム全体の復元は主張していない。

この基準は基本的なMBAであり、Tigress等の全機能や強い既存方式を代表する比較を完成したわけではない。新方式を含む公平な三者比較もまだない。攻撃器の未対応範囲を利用して候補を成功扱いしない。
