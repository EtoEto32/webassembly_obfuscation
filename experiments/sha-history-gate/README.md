## 4. 検討した規則と意味保存

すべて32ビットワード。加減算は modulo 2^32、Σ0は右回転2,13,22のXOR、Σ1は6,11,25のXORとする。Q(x,y,z)=Σ0(x)+Maj(x,y,z)。

候補座標 p=(p0,…,p7) から通常状態を次で定義する。

```text
Ej = pj + p(j+4) - Q(p(j+1),p(j+2),p(j+3))  (j=0,…,3)
D(p) = (p0,p1,p2,p3,E0,E1,E2,E3)
N = E3 + Σ1(E0) + Ch(E0,E1,E2) + u + Q(p0,p1,p2)
U(p,u) = (N,p0,p1,p2,p3,p4,p5,p6)
```

uはK+Wに相当する任意の32ビットワード。通常状態sからpへの逆写像は、最初の4語をコピーし、j=0から3へ順に `p(j+4)=s(j+4)-pj+Q(p(j+1),p(j+2),p(j+3))` と求める。各右辺は計算済み座標だけを使うため、全256ビット状態上の全単射である。初期pを実在した過去のSHA軌道と解釈する必要はない。

通常ラウンドをFとすると `D(U(p,u))=F(D(p),u)`。先頭4語は直接一致する。次のE0は `N+p3-Q(p0,p1,p2)=T1+p3`、残りのE語は旧E0,E1,E2になる。したがって `U=D⁻¹∘F∘D` という通常の共役変換である。これは代数的導出であり、SMT証明を実行したという主張ではない。

## 5. 先行研究と新規性評価

調査日2026-10-12。先行する探索の検索語は `SHA-256 alternative description recurrence eight state variables a e eliminate`。今回、Dobraunig・Eichlseder・Mendel, *Security Evaluation of SHA-224, SHA-512/224, and SHA-512/256* (February 2015) の表紙、§1.1の式(1.2),(1.3)、§1.3を確認した。[CRYPTREC元の資料](https://www.cryptrec.go.jp/exreport/cryptrec-ex-2401-2014.pdf)。

| 比較項目 | 評価 |

## 8. 攻撃実験・比較

攻撃者は座標順序とDを知り、各pを受け取り、通常状態の8ワードの完全復元を目的とする。Dは過去のトレース、秘密、入力uを必要とせず、4回のQ評価で復元する。保存試験では67,200状態で一致した。ただしこの数値は等価性チェックと同じdecode呼出しの集計であり、67,200件の独立した攻撃ではない。バイナリ中の変数同定、座標順序の発見、盲目的逆コンパイルは未評価。plain/MBAとの公平な攻撃比較は未実施、優位性は示されない。
