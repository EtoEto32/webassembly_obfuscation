# 組紐による回路変換の既存プリミティブ監査

## 1. 最終状態

2026-10-12。**判定はInconclusive。新規アルゴリズムを発明するという研究目標は未達で、状態はactive（継続中）である。** 今回は、最近検討していた状態の座標変更とは異なる生成原理を調べ、既存研究の可逆ゲートを限定的に再現した。新しい方式を発明した結果ではない。

## 2. 達成事項

「可逆ゲート列を群の関係式で書き換え、正規形に変換して元の分割を分からなくする」という案に対応する先行研究を特定した。公開式R(a,b)=(b,b^-1ab)をA5上で実装し、可逆性、組紐関係、位数を有限領域のすべての入力で確認した。関係式による同値性と実行結果の同値性が一致しない具体例も保存した。

## 3. 未達事項

独自の生成規則、Wasm難読化変換器、SHA全体への適用、公平な攻撃比較、既存方式に対する優位性は、まだ実現していない。以下の照合件数は有限ゲートの恒等式を確認した回数であり、保護効果を評価した試行数ではない。

## 4. 規則・成立条件

A5は、5点上の偶置換60個からなる群である。積abはa○b、すなわちbを先に適用するものとする。a,b∈A5に対してR(a,b)=(b,b^-1ab)と定義する。出力(c,d)から入力を(cdc^-1,c)として求められるため、この写像は可逆である。

3要素の隣接対への作用R1,R2は R1R2R1=R2R1R2 を満たす。離れた対への作用は可換で、RとR^-1の相殺も正しい。これらを使う書き換えは状態への作用を保つ。

今回のA5ゲートRの位数は60である。したがって、同じ2要素にRを60回作用させる回路は恒等回路と等しい。一方、抽象組紐のσ1^60と空語は等しくない。正負の生成子を±1として加えた指数和はすべての組紐関係で保存されるが、両者の指数和は60と0で異なるからである。つまり、関係式で定まる同値類だけでは、実装ゲートの意味的な同値性をすべて捉えられない。

この違いだけで、攻撃が困難になるとは判断しない。60回のゲートを削除するだけなら、この意味的な関係を知る解析者には容易である。一方、任意の回路の同値判定や復元まで解けたことを示す結果でもない。

## 5. 一次資料・新規性

Alagic, Jeffery, Jordan, [Circuit Obfuscation Using Braids, TQC2014](https://drops.dagstuhl.de/storage/00lipics/lipics-vol027-tqc2014/LIPIcs.TQC.2014.141/LIPIcs.TQC.2014.141.pdf), DOI 10.4230/LIPIcs.TQC.2014.141。2026-10-12に定義2、§1.2.3、§3.2式(2)、§5.1、§6.2の該当箇所を確認。関係集合に限定した識別不能性と群の正規形の構成は既知。位数60と追加関係σ_i^60=1も論文中にあり、今回の発見ではない。

§5.1はコンパイル後の構造を使う攻撃を説明するが、誤ったゲート推測の判別には限定的な試験に基づく記述がある。これを全入力で証明済みの攻撃成功や、本リポジトリで再現した結果と扱わない。

| 比較項目 | 判定 |
| --- | --- |
| 数学的原理 | 群の関係式・正規形による変換は先行例と同じ |
| 表現 | A5要素と可逆ゲート列も既存 |
| 状態変換 | 公開されたRをそのまま再現 |
| 依存関係 | ゲート分割をまたぐ関係式があるが既知 |
| 困難性の原因 | 関係式上の正規化の保証と、実際の復元の難しさは別 |
| 一般化 | Wasm/SHAへ移植するだけでは独立した新規性を示さない |

検索語: `program obfuscation "word problem" group rewriting`、`code obfuscation "proof complexity" rewriting`、`obfuscation "braid" group program`。他の検索結果を本文を確認済みの根拠として使わない。元の研究目的に対して、新規性未確認のまま大きなToffoli/SHAコンパイラを作らないという採否判断を得た。

## 7. 実装・結果

protocol.jsonを事前保存。check.pyはA5を辞書順に列挙し、積・逆元・Rの表を生成する。乱数なし、標準ライブラリのみ。

- 3,600組でRが置換となることを確認。
- 全216,000三つ組で組紐関係が一致。
- Rの巡回長と個数: 1:60、2:120、3:100、4:210、5:72、6:140、10:96。
- 巡回長の最小公倍数は60。さらに全3,600組でR^60=idを直接確認。

すべての表と巡回分解をartifacts/tables.jsonに、集計をresults.jsonに保存した。著者コードは使わず、公開式から実装した。著者の難読化器、正規形アルゴリズム、普遍性の証明、攻撃を再現したものではない。Wasm・SMT・SHA全体は実行していない。
