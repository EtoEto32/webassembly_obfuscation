# 内部解の非一意性と出力の一意性を分ける追試

1. **状態: Inconclusive**。全体の新しいアルゴリズム目標は未達成で継続。この追試は候補採用時の誤判定を防ぐもので、難読化アルゴリズムの発明ではない。

2. **達成事項**。前回保存した65,536系の根集合を独立した多項式評価で照合し、3種類の復号関数について出力を列挙した。複数内部解があることだけでは候補を棄却できない。一方、以下の微分条件を満たすだけでも正当性を認められない。

3. **未達成事項**。この追試から、新規原理、Wasm変換器、SHA-256の新規変換、比較上の優位性は得られていない。有限環上の正当性条件の整理を、Goal第13節の完了に数えない。

4. **数学的仕様**。固定入力 a に対して内部状態 z は F_a(z)=0 の解、観測出力は多項式 D(z) とする。w>=2、全内部語タプルが合法と仮定する。必要な性質は根 z の一意性ではなく、空でない根集合における D の定値性である。前回の展開を F と D の両方に適用すると、各根 z で

       ker(DF_a(z) mod 2) ⊆ ker(DD(z) mod 2)

   が出力一意性の必要条件となる。左の核の方向 h に最上位ビットだけを変えると別の根が得られ、D の変化は 2^(w-1) DD(z)h になるためである。条件は同じ下位 w-1 ビットを持つ根の間だけを制約する。異なる下位ビットを持つ根の出力一致は保証しない。全入力での関係、実行手順の停止性、選択した内部状態の到達可能性、更新時の不変条件保存は別途必要。

5. **先行研究・新規性**。2026-10-12、Stephen Drape, [Obfuscation of Abstract Data-Types](https://www.cs.ox.ac.uk/files/2892/thesis.pdf)、§3.2、本文49頁の抽象化関数・不変条件と式3.1–3.3を再確認。複数具体状態を一つの抽象状態へ写す枠組みが既存である。今回の微分検査そのものの掲載を確認したわけではないが、基本的な多項式展開から出る正当性条件を独立した保護原理とは扱わない。

   | 比較項目 | 本追試と既存枠組みの関係 |
   | --- | --- |
   | 数学的原理 | 抽象化関数による多対一表現の範囲内 |
   | 表現体系 | 多項式関係を満たす内部状態、既存の冗長表現と共通 |
   | 状態変換 | 新しい閉じた更新規則は未設計 |
   | 依存関係 | 解の選択から観測値を独立にする、という意味が保存される条件 |
   | 解析困難性 | 本条件からは導けない |
   | 一般化可能性 | 微分条件は任意変数数・w>=2、実験は2変数mod4のみ |

   検索語は `software obfuscation redundant state encoding homomorphism quotient automata bisimulation`。検索で得た一般論を新規性の否定証拠とせず、上記一次資料と既存実験の具体的な規則で照合した。DataMeldの検索も行ったが既に `tmp/datameld-audit/README.md` で具体的な規則を確認済みだったため、本検証の新しい証拠として数えない。

11. **Before / 想定関係の例**。以下は表示用の関係例であり、Wasm変換器の生成物ではない。

       Before: return 0
       関係A: F=(x,0)=0 mod4; return D=x
       関係B: F=(x+y-1,xy)=0 mod4; return D=x

   Aの根は(0,0),(0,1),(0,2),(0,3)。すべて出力0なので内部解は唯一でなくてよい。Bの根は(0,1),(1,0)で、両根ともヤコビ行列は正則だが出力は0/1となる。Bは微分条件を満たしてもBeforeの意味を保存しない。両方をcontrolsとしてコードで確認した。一般的なAfter実装・最適化後コードはない。
