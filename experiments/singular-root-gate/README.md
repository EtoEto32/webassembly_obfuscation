# 特異ヤコビ行列による暗黙出力方式の修正案

後続の[出力射影を含む追試](PROJECTION.md)では、内部解の一意性を必要としない場合を分離した。本報告の結論は全内部語がそのまま出力になるモデルに限定する。

1. **状態: Inconclusive（全体目標は継続）**。この修正案は下記モデルで棄却する。新規難読化アルゴリズムは得られていない。

2. **達成事項**。保存されていた検証コードと入力計画を読み、2026-10-12に独立した出力ディレクトリで再実行した。mod 4 の双線形2変数2方程式65,536系で、唯一の解を持つ18,432系のうち、その解のヤコビ行列が特異な系は0。有限実験に加え、任意の幅 w>=2 に対する直接の理由を以下に示す。

3. **未達成事項**。独立した新規原理、再利用可能な新規Wasm変換器、提案方式のSHA-256適用、既存方式への解析困難性の優位性はいずれも未達成。今回の棄却検証をこれらの代替成果と扱わない。

4. **検討した規則と成立条件**。外部入力を固定し、出力 z∈(Z/2^w)^m を r 本の多項式 F(z)=0 で一意に指定する方式を対象とする。すべての語タプルを合法な出力とする。「根で J=DF(z) mod 2 の列ランクを落とし、単純な持ち上げを妨げる」という修正を検討した。

   h∈{0,1}^m に対して多項式の展開より

       F(z + 2^(w-1) h) = F(z) + 2^(w-1) DF(z) h  (mod 2^w).

   二次以上の項は 2^(2w-2) の倍数で、w>=2 なら消える。従って z が根なら、この最上位ビットだけを変えた点が根になる条件は Jh=0。異なる h は異なる点を与えるので、同じ下位 w-1 ビットを持つ根は正確に 2^(m-rank J) 個ある。根の全体での一意性には列フルランクが必要であり、特異化と両立しない。これはフルランクなら全体の根が唯一である、という十分条件ではない。

5. **先行研究と新規性**。2026-10-12、既存記録の参照先を直接再閲覧: Keith Conrad, [A Multivariable Hensel's Lemma](https://kconrad.math.uconn.edu/blurbs/gradnumthy/multivarhensel.pdf)、導入・定理3.3とNewton更新の説明。今回新たな検索語は使用していない。資料は p 進数上でヤコビ行列を用いた根の局所的な持ち上げを扱う。上の有限剰余環での必要条件は直接展開で説明したもので、資料の定理そのものと同一とは主張しない。

   | 比較項目 | 判定 |
   | --- | --- |
   | 数学的な原理 | 既知の多項式展開・線形代数に基づく |
   | 表現体系 | 既存の暗黙多項式表現の範囲 |
   | 状態変換 | 実装可能な新しい状態変換を確立していない |
   | 依存関係 | 特異化による修正は出力の一意性を失う |
   | 困難性 | Hensel更新を妨げるだけでは保護根拠にならない |
   | 一般化 | 定義した多項式・全出力領域に限る |

6. **過去成果の再利用**。`tmp/residual-root-lifting/README.md` と既存の実験コードを研究上の参考（分類C）として利用。同実験の根の計算は正規の実行手順であり、ソース復元攻撃ではない。既存のSHA基盤を今回作り直していない。保存済みの `check.py` と `protocol.json` は再実行に成功し、この限定検証には分類Aとして利用できる。

7. **実装・検証結果**。Python 3.12.14、標準ライブラリのみ。双線形多項式256個のすべての順序付き対と全16入力点を確認。特異な根の出現40,960件、核方向の移動照合114,688件。これらは異なる「攻撃数」ではない。全分類を `classifications.json` に保存。32ビットでは seed=271009 の根を埋め込んだ二次多項式256系について4方向ずつ、1,024点を照合した。核サイズ1/2/4の系は81/159/16。32ビット全領域の列挙でも、256系の根が唯一であるという結果でもない。w=1の平方関数と4ビットrotateを対象外の対照として含む。

8. **攻撃・比較**。新しい攻撃実験は実施していない。今回の判定対象は意味保存の必要条件。根の計算、元コード復元、難読化除去を同一視しない。plain・既存方式・提案方式の公平な比較を完了したとは主張しない。

9. **費用と残存性**。Wasmバイナリ、速度、サイズ、wasm-opt残存性は本案では未測定。初期条件が破綻するためSHAバックエンドを実装しない。探索計画の上限は20分、各コマンド60秒、パラメータ拡張0。再実行コマンドは1秒未満で終了したが、これは難読化性能の指標ではない。

10. **改善サイクル**。元の暗黙残差方式は正則なヤコビ行列で根を持ち上げられた。今回の修正仮説は特異化であり、その代償として別の合法出力が必ず生じることを確認した。この修正案の係数探索を延長しない。一般の難読化方式を否定する結果ではない。

11. **Before / 想定After**。未実装候補なので、以下は生成済み難読化コードではなく、棄却した関係式の表示例である。

       Before: z=f(input); t=g(input)
       想定After: 2*(z-f(input)) = 0; t-g(input) = 0  (mod 2^32)

   想定Afterは (f,g) に加え (f+2^31,g) も許す。変更箇所は最初の残差への2倍の乗算であり、一意な出力という仕様を失う。一般のAfter生成器・最適化後コードはない。追加の根選択規則を付ける場合は、その規則を含む別方式として正当性と保護機構を評価する必要がある。

13. **限界と次の判断**。w=1、非多項式の語演算、合法出力が制限される場合、複数内部状態を同じ観測出力へ写す方式には結論をそのまま適用できない。多項式の追加条件はすべての行を含むヤコビ行列で評価する必要がある。根の個数だけでは、複数状態を許す難読化の不可能性も解析容易性も示せない。次の設計は、許される複数内部状態と観測出力の意味を明示し、既存の冗長状態符号化と異なる原理を先に示す必要がある。この記録に新規性を認めて全体目標を完了させない。
