# 実装前の成立性・先行性ゲート：奇数長トレース

2026-10-21。copy-fiberでは局所の復号と再符号化が相殺された。その境界をなくすため、
算術式全体を重み付き閉路へ移し、行列のべき乗のtraceだけで答えを得る方向を検討する。
これは採用済みの新発明ではない。

等長Lの閉路によりfを実現すると、通常のtraceは各始点を数えるのでL*fとなる。
mod 2^32では偶数Lを逆算できず、Lを奇数にして逆元を掛ける必要がある。
普通のunsigned整数除算はwrap後の値から元のfを戻せない。

ただしIkenmeyer–Landsbergの既存論文Remark 4.5に、層付きABPを閉路へ移し
行列べき乗のtraceで評価する構成がある。奇数へのpaddingは単元条件への対応であり、
これだけを独立した難読化原理・新しい固定点理論・特許の核と主張しない。

大規模な難読化器を作る前に次を検査する。

1. f=(x+y)*(z-t) mod 2^32を重み付き閉路として実Wasmで評価する。
2. L=3,5,7の逆元補正はraw/O3で境界・random入力と一致するか。
3. L=2,4,8では異なるfが同じtraceになる実例があるか。
4. 方式・binary既知の解析者が、元式なしに閉路の重み積へ戻せるか。
5. 閉路長だけを増す修正に意味保存以外の新規性・保護根拠があるか。

このゲートが既知構成の直接的な移植・安い復元を示すなら、追加の性能sweepや
任意式compilerを作らず棄却理由を保存する。全体の発明目標は継続する。
