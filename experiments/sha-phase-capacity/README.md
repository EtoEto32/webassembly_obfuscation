## 4. 数学的仕様・証明

S=({0,1}^32)^8、iは次に実行するラウンド番号。T_i(s,w) は標準SHA-256の1ラウンド。全加減算はmod2^32。Q(a,b,c)=Σ0(a)+Maj(a,b,c)。検討した案は、有限集合Z、任意の関数E_i:S→Z、**位置に依存しない**D:Z→SとU_0:Z→Zを用い、すべての到達可能な(s,i,W_i=0)について次を満たす。

```text
D(E_i(s)) = s
D(U_0(E_i(s))) = T_i(s,0)
```

U_0はW=0の場合の共通更新。i、K_i、PC、アドレス、メッセージ全体、スケジュールメモリを別途読むことは許さない。復号器が存在するという意味論的条件であり、攻撃者がDを知るとは仮定していない。候補の希望は |Z|≤2^256。

### 到達性

固定u=K_i+W_iでのラウンド逆写像は、次状態(A,B,C,D,E,F,G,H)から

```text
t1 = A - Q(B,C,D)
s = (B,C,D, E-t1, F,G,H, t1-Σ1(F)-Ch(F,G,H)-u)
```

と一意に求まる。前進式に代入すれば恒等写像になり、固定uのラウンドは全単射。

任意の目標sとi∈{8,...,15}について、W8..15をすべて0とし、i-1から8までこの逆写像を適用して境界8の目標s8を得る。既存の `sha-prefix-reachability/README.md` §4の全称構成でW0..7を選べば、標準IVからs8へ到達できる。この8語に8個のゼロ語を連結した64byteメッセージは、境界iでs、かつ現在W_i=0を実現する。パディングは次ブロックに入る。

これにより8境界それぞれでS全域が到達可能。i=16で現在W16も0になるとは主張しない。W16は最初の16語から生成されるため、この構成からは従わない。

### 容量

D∘E_i=idだから各E_iは単射。仮にi≠jでE_i(s)=E_j(t)なら、Dを適用してs=t。一方U_0とDを適用するとT_i(s,0)=T_j(s,0)が必要。しかし両者のaとeの差はK_i−K_jで、それ以外の6語は同じ。K8..K15は互いに異なるので等しくなれない。よって8個の像E_i(S)は互いに素で、

```text
|Z| ≥ Σ_i |E_i(S)| = 8 × 2^256 = 2^259.
```

従ってこの条件で256bitだけに詰め込む案は不成立。259bitで全SHAを実装できるという十分条件でも、最小容量が厳密に259bitという主張でもない。全称結論は上の証明による。有限32入力の試験だけから導いていない。定理証明支援系やSMTによる機械検証は未実施。

## 13. 限界と未解決課題

共通Dを仮定しない共同符号化、外部PCやメモリを読む更新、別の中間表現、同じ最終ハッシュだけを計算する別アルゴリズムは排除していない。256bit作業状態のみの容量と完全なプログラム状態の容量を区別する。通常SHA実装に追加3bitが必要という意味でもない。今回の限定案を棄却しただけで、新しい難読化原理は得られていない。§13の完了条件は未達のまま維持する。
