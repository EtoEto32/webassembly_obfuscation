# 元の論文に沿った採掘機能・性能の検証方針

2026-10-07に改訂した検証方針である。具体的な設計はexperiment-design.mdを参照する。

元の論文 WebAssembly diversification for malware evasion のRQ3と公開実装に従い、通常版と変換版の採掘処理を実行する。プールによる結果の受理・拒否と、約1,000秒のハッシュ計算速度を評価する。

前案で独自に設定した、4手法の選定、3回の繰り返し測定、固定入力による出力照合、ウォームアップ、初期化時間の評価、保存したジョブの再実行は撤回する。元の論文の本文と公開コードの違いは設計書に記録した。

対象アルゴリズムとプールの互換性を確認し、利用者自身の受取アドレスを使用する。通常の採掘通信だけを行い、外部への攻撃や無断の資源利用は行わない。

この改訂時点では、外部プールへの接続・採掘は未実施であり、隔離設定も変更していない。pilot-manifest.csvは撤回した前案の記録であり、実行対象にしない。
