## 4. 候補の規則と意味

本族はw=4,8,16,32、M=2^w、a=2^(w/2)+1、b=3、c=(2a−1)/3とする。a²−bc=M、a>b,cである。非負整数の粒数z=(z0,z1)に対し、次の合法な更新を行う：

```text
z0 >= a : z <- z + (-a, b)
z1 >= a : z <- z + ( c,-a)
```

各更新は総粒数を厳密に減らすので停止する。S(z)は両粒数がa未満となるまで合法に更新した結果。本実装は一頂点の連続更新を整数除算でまとめる。元の各1回の更新は合法であり、任意の負数を投入して安定化するものではない。

奇数rを固定し、E_r(x)=S((r*x mod M,0))とする。変換規則は

```text
Before: s = (x+y) mod M
After:  z = S(E_r(x) + E_r(y))
```

符号化した和zを後続加算へ渡す。D_r(z)=(3r)^(-1)*(3*z0+a*z1) mod Mで通常の値に戻る。

F(z)=3*z0+a*z1について、頂点0の更新差は−3a+ab=0、頂点1では3c−a²=−M。従って安定化の途中もFはmod Mで不変。F(E_r(x))=3rxなので、D_r(E_r(x))=x、D_r(S(E_r(x)+E_r(y)))=x+y mod Mである。これは全幅入力についての代数的根拠。SMT証明ではない。

E_rの像が再帰配置の全体だとは仮定しない。安定な配置の集合には同じ値を表すものがありうるが、上述のデコードが正しいため加算の反復は成立する。SHAのXOR、回転、Ch等をデコードせず実行する規則は未定義。安定化の合法実行順の一意性は砂山モデルの既知性質であり、今回も順序を逆にした結果を各加算で照合した。

狙いは、加算を入力依存の循環した更新列へ変えて算術関係を隠すことだった。基礎表現と更新原理が既知で、線形読み出しも残るため、新しい情報依存性の原理とは認定しない。

## 8. 観測者と復元実験

観測者はmodulus、2つの符号付きtopplingベクトル、各頂点の粒数を知る。既知の入力1を一度符号化した配置を取得できる。生成用r、他の平文x,y、期待する和はobserverへ渡さない。ソース・バイナリから更新行列を抽出する前処理は実装していない。プロセス隔離した盲検ではなくコード上の情報分離である。

第1ベクトル(-a,b)からv=(b,a)を作り、両更新の内積が0 mod Mであることを確認する。t=v・E_r(1)=3r mod Mは奇数なので逆元がある。返す係数はt^(-1)vであり、その線形結合で全観測値を復元できる。これにより未知rも既知入力1で除去される。各設定の式について、更新差を消すことと初期(r*x,0)に対する係数が1になることを整数で確認している。

安定化の終了時を探す必要すらなく、途中でも同じ値を読める。入力依存の更新回数や順序変更はこの復元を妨げない。一般的なグラフ・未知バイナリからの復元や、他の難読化との勝率比較までは主張しない。本限定モデルでの否定結果のみ。
