    公開 WebAssembly データセットにおける採掘プログラム
          の難読化手法と静的コード変化の分析

                                                     著者名（要記入）1



             概要：WebAssembly を用いたクリプトジャッキングの研究では，収集された採掘プログラムと研究用に生
             成された難読化版が公開されている．本研究は，これらの配布物で確認できる難読化手法と，難読化によ
             る静的なコード変化を分析する．配布元の変換設定，バイナリの特徴，命令列から確認した機構を分けて
             整理した．Cryptic Bytes の採掘 10 プログラムについて，基準版を含む 20,460 件の対応比較を行い，元プ
             ログラムごとに変化量を集約した．代表例では，状態を更新する平坦化，命令列を読み出す仮想化，等価
             な算術式への置換，メモリから得た番号を使う間接呼出しを確認した．未最適化配布版では，Tigress の算
             術式符号化の命令数比の中央値は 2.515，仮想化のファイルサイズ比は 1.834 であった．最適化済み配布版
             ではそれぞれ 1.655，2.322 となり，命令数とファイルサイズは異なる傾向を示した．仮想化では code に
             加えて data セクションが増え，基準版の大きさも倍率に影響した．複数の公開資料で変換設定と構造を整
             理した一方，収集検体の手法別普及率までは確定していない．本稿は静的な変化を示すものであり，採掘
             性能，実行時負荷，検出回避能力は評価していない．




    Obfuscation Methods and Static Code Changes in Mining Programs
                  from Public WebAssembly Datasets
                                                       Author Name1



             Abstract: We investigate declared transformations, observable mechanisms, and static code changes in pub-
             lic WebAssembly artifacts for cryptojacking research. For ten related mining programs in Cryptic Bytes, we
             analyze 20,460 paired records including identity baselines, aggregating changes within each source program.
             Selected cases exhibit state-based ﬂattening, a bytecode interpreter, arithmetic substitution, and memory-
             derived indirect calls. In the unoptimized release, the median instruction ratio for arithmetic encoding is
             2.515 and the median ﬁle-size ratio for virtualization is 1.834. The corresponding ratios in the optimized
             release are 1.655 and 2.322. Section-level analysis shows that virtualization changes both code and data,
             while baseline size also aﬀects relative growth. We distinguish declared settings and structural indicators
             from locally veriﬁed mechanisms. These observations do not establish prevalence in deployed attacks. Mining
             performance, runtime overhead, and detector evasion are outside this static study.
