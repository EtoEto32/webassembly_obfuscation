# 一般SMT対照の実装依存性を検査する

2026-10-24。先の25–34倍という人工read-chainでの速度差が、比較対象の単純な実装のためかを調べる。Kの等式集合・copy-map・条件は使わず、一般SMT式に対する既知の実装改善だけを追加する。

各edgeの変数置換を一度作り、式中に実際に現れる変数だけを置換する。同じsuccessor式のWP/QEをcacheし、構文的に同一の固定点式にはSMT queryを省く。SMT solverはdomainを一度assertしpush/popで再利用する。qe前のsimplifyで量化が消えた場合もsolver呼出しを省く。特定のchain形や正解条件を認識するshortcutは置かない。

先の256契約と8chainで同じ初期条件になることを独立に検査した後、同じ3 process・2 warmup・5反復の計測を実施する。準備・cache構築も条件合成費用に含める。旧一般対照の測定値を消さず、強化した比較対象を併記する。差が縮む/逆転する場合はそのまま報告する。
