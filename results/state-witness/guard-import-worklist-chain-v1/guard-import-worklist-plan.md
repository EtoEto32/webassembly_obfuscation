# 等式義務のworklistによる反証用比較

2026-10-24。直接反例の再現package v3検査後に固定する計画。

Kの条件合成が、既知の有限・分配的データフロー計算としても実装できるかを調べる。新方式の命名や独立した発明数の追加は目的にしない。参考はReps/Horwitz/Sagivの[Precise Interprocedural Dataflow Analysis via Graph Reachability](https://doi.org/10.1145/199448.199462)、POPL1995。今回の課題には同論文の手続き間valid-path処理は必要なく、引用は分配的有限factの既知性を示すためである。著者toolの追試とはしない。

各寿命状態対に必要な等式atomを保持し、追加されたatomだけを前任edgeへ逆伝播する。局所観測を種にし、canonical化で矛盾となった状態のfalseも伝播する。通常の全状態・全条件反復との違いは計算順序で、parser・一段WP・等式正規化は共有する。そのためこの比較は独立意味論検査ではない。

旧256契約、may128契約、遅延chainの16契約で、初期条件と各寿命対の条件が全反復版と一致することを検査する。任意Nの停止は有限atom集合から従うが、実装にはstate/fact上限を置き、到達をunsupportedとして区別する。反例列やrank層は生成しないので、反例付き解析との性能同一課題にはしない。

条件だけの費用を測る場合は、同じparse済みmodelから状態graph構築・条件生成・出力正規化を含め、各方式3process、2warmup＋5反復とする。速度は実測後に記載する。旧版のrank層は旧版実装に保持されるが、この比較の出力契約は条件のみである。この実装差を速度表と共に明記する。
