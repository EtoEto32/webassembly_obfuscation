# 可変多項式表現の反証計画

2026-10-21。新しい難読化の発明ではなく、既存の静的多項式表現を可変辞書へ
延長する前の棄却条件を調べる。研究全体の完了とはしない。

固定した相異なるキー集合、既存キーへのset、32bit値、lookupのみを意味とする。
private memoryの物理バイト列は抽象辞書の意味に含めない。外部memory、共有memory、
import、挿入・削除・任意のWasm入力を対象にしない。実Wasmのfixture生成器を作る。

仮説：Pを根多項式、Rを次数n未満の補間多項式とすると、1件の非零更新の差Dは
alpha*P/(X-k)。n>=2では k=D[n-2]/D[n-1]-P[n-1] (mod p)。因数分解なしで
更新キーを回復できる。n=1はPから直接分かる。値の上位商も別多項式で保持する。
値の変化がpの倍数で下位差が零の場合も検査する。

解析者へ渡すのは公開formatの更新前後の係数snapshotだけ。元辞書、更新引数、
乱数seedを渡さない。通常のデバッガで引数を読むより制限した観測モデルである。
snapshot取得用memory exportはprivate版の生成・O3適用後に追加する。
中間状態の観測耐性は主張しない。作業用商多項式はsetの終了前に消す。

配列対照と多項式版のraw/O3、独立JS Mapとの逐次差分テストを行う。境界値、
高位商だけ変わる更新、no-op、存在しないキー、例外5キーを含める。
2件の異なるキーを変えたsnapshotを単一更新として誤認しないか検査する。
候補キーはD*(X-k)=alpha*Pを全係数で照合し、安い候補抽出と検証を区別する。
ツール失敗・不一致は成功に含めない。攻撃本体時間は同一process反復の診断値とする。

単純な更新差分で成功すれば、この拡張を主発明にしない。Pの倍数をRへ足す
再符号化も、剰余を取ると同じ差が残るため修正候補として採用しない。
