# ビット依存関係による有限更新候補：事前仕様

2026-10-18。特許を目指すという追加指示を受けた研究用の限定候補。採用・新規性・出願可能性は未判定。暗号学的な解除不能性を要求しない。

## 構成と検証する差分

純粋な i32 SSA 計算を v_i = F_i(v,x) とする。F は語単位の DAG。
各 j > i について G_ij(z) = (z << k) & m を選び、

    H_i(v,x) = F_i(v,x) XOR XOR_j G_ij(v_j XOR F_j(v,x))

を同時更新する。G が語順について厳密上三角なので、固定点では (I XOR G)(v XOR F(v,x))=0 より v=F(v,x)。G の逆は有限和であり秘密ではない。

一律のマスクでは右シフト・回転で循環が生じ得る。候補の具体的規則は、F の保守的なビット依存 DAG にフィードバックの各ビット辺を順に挿入し、閉路を作るビットをマスクから除外すること。さらに最長路の長さを予算以下に制限する。残差内の F_j の依存は j への既存辺と追加辺の合成で覆われる。合成グラフが非巡回なら、その最長路の頂点数を上限とする同期更新で全ビットが確定する。

循環回路、固定点実行、ビット依存解析は既知。差分の候補はこの残差構成とマスク・更新回数の共同生成規則に限る。Wasm 固有の新原理ではなく、i32 の剰余演算・シフト仕様に合わせた変換であり、Wasm で実装しただけを新規性としない。

## 入力範囲

実 .wasm、単一の純粋な関数、i32 引数と i32 結果一つ、直線コード、local、定数、add/sub/mul/and/or/xor、定数シフト・回転。メモリ、import、呼出し、global、ソースの分岐・ループ、trap を起こす演算、浮動小数点は拒否。最大 32 演算節点。戻り値以外の副作用はない。

## 固定した実験

- 右シフト・回転・算術を含む小カーネル。plain、フィードバックなしの同期更新、全ビット許可の提案を閉路検査して採否する方式、ビット選択方式を比較する。同一 seed・提案順序。
- 最適化 raw/O2/O3。正当性は境界値と固定 seed の乱数、各種初期状態、小幅の全列挙、別エンジンによる一部照合。全入力の実行検査を数学的証明と呼ばない。
- 方式を知る解析者がバイナリから更新式を読み、ビットの固定点方程式を依存順に評価する。元の Boolean DAG と比較する。変換レポート・seed・元バイナリを解析入力にしない。未対応は解析失敗・保護成功と数えない。
- 実行時間、サイズ、変換時間、更新回数、linear memory とプロセス RSS、解析時間を記録。小カーネルの JS 呼出し費用を含む測定であることを明示する。
- 成功条件：適用範囲拡大を確認するだけでは不十分。先行技術との差と、同程度の実行費用での実用的な解析負担増加が必要。回復できたという理由だけで棄却せず、回復費用と保護側の費用を対比する。

## 予想される最大の弱点

ビット DAG の生成に用いた非巡回性が、そのまま解析者の回復手順を与える。残差が局所的に相殺される可能性も高い。US7249341B2 の循環回路合成、Riedel/Bruck DAC2003、Shamsi ほか GLSVLSI2017 と、既存の固定点・残差実験を照合する。安全なコード生成手順の技術効果と、難読化の保護効果を分けて判定する。
