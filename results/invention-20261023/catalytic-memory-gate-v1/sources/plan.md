# 内容不明の領域を借りる計算：早期反証計画

2026-10-23。span-maskの第3候補を具体化する。既知のdirty ancilla/reversible computationに近いため、新発明と仮定しない。本格的な性能評価の前に、未知の初期値を固定する解析と途中trapによる破綻を試す。

仮説：借りたwordを元に戻す計算へ変換すると、初期値を知らない解析者に追加の復元負担が生じる。

基本構成：cを借り、c+=x、r=c*y、c-=x、r-=c*yとする。結果はx*y mod 2^32でcは復元する。ANDでは加減算をXORに、乗算をANDに置く。これは既知の可逆・差分恒等式の具体化であり、この式自体を新規と主張しない。生成器は限定した実Wasmを受け取る。

解析者に元式は渡さず、memory SSAと代数正規形から初期wordへの依存消失、最終memoryの一致、各trap点のmemory一致を確認する。確認できれば初期wordを0へ特殊化し同等の通常Wasmを出力する。unknownを秘密として扱わない。

元版・借用版のraw/O3、3例（AND、積、積を入力で除算）、境界値と乱数、全memory、division-by-zeroを比較する。途中除算してから戻す不正版も作り、trap後の破損を必ず検出する。uncomputeを除算前に行う版を正条件とする。対象外機能・解析未対応は別集計。

この原理が既知で、さらに方式既知の小さい解析で消せる場合は早期不採用とし、規模だけを増やした性能試験を実施しない。
