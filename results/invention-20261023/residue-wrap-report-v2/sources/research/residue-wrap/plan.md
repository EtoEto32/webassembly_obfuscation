# 剰余表現とWasmのwrap意味論：成立性ゲート

2026-10-23。既存RNCを新発明と数えず、異なる法の算術をWasm i32へ直接移す際の成立条件を確認する。剰余系の法Mで評価後にi32へ戻すだけでは、Mによるwrapが結果へ影響する。加算・減算・乗算を任意に合成する全域変換について、Mが2^32の倍数なら射影が保たれる。互いに素なmoduliでこれを満たすには、一つのmodulusが2^32の倍数を含む必要があり、そのchannelの下位32bitに元の値が残る。

実.wasm入力から純粋な2引数i32式（add/sub/mulと定数）を読むCLIを作る。比較はplain、odd（65537,65539で成分演算する未修正版）、repair（各演算でCRT復元→i32演算→再符号化）、aligned（2^32,65537で成分演算）。oddは負の対照であり、正しい難読化方式として性能順位へ入れない。alignedには下位32bit射影の適応的回復を試す。

境界、固定seedのランダム入力、raw/O3を照合する。縮小幅の全入力でも確認する。RNCの論文実装を実行したり、当該著者実装にバグを確認したとは主張しない。対象は本研究で明示した移植規則。修正が成立しても既知CRT/環射影の利用だけなら主特許候補にしない。性能・サイズ・変換時間・記憶量と追加保護の有無を区別する。
