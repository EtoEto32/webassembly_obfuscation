# 解除器の適用範囲を調べる事前計画

2026-10-23。新しい難読化方式を評価するとき、専用の生成形式に対する解除と、意味を保つ変形後の解除を分ける。これは発明件数を増やす実験ではない。

対象は既存mutable-factorの6個の人工グラフ。未変更、局所変数の置換、無意味な加算、guard順序変更、partnerをXOR/積和/selectで選ぶ変更の7種を作り、rawとBinaryen133 O3を検査する。最後の3種は物理状態を変えるが、Aが置換ならN=B∘Aの更新意味は同じである。各選択式が有効な入力上で0<=w<nを満たすことを32bit SMTで確かめる。

未変更の旧解除器を全条件に適用し、成功、形式未対応、クラッシュ、タイムアウトを別集計する。形式未対応を難読化成功と数えない。全候補をNodeで同一の境界値・乱数・連続呼出しにかけ、値とtrapを独立JSモデルと照合する。private memoryの物理一致は要求しない。負の対照として範囲を外れるpartnerとBへのstore順序を逆にした版を検査する。

判定基準：同値変種で旧解除器が拒否した場合、その拒否は形式依存の実測となる。既存の任意wに対する一更新の論証が適用できる場合には、方式の保護原理が改善したとは判定しない。一方で、本実験で一般的なWasmの解除を達成したとも主張しない。新規候補の次の評価では、元のテンプレートとの完全一致だけを受理条件にした解除時間を、広い解析耐性の数値として扱わない。
