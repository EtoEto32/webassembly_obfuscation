# 次段階：普遍Boolean補正器を整数へ持ち上げる

2026-10-23、bitwise版の局所固定点列挙を受けた仮説を実装・実験した。正当性検査は通過したが、元の演算断片を使う適応解析で全6条件を回復した。主特許案には不採用。新規性は未確立。

3座標FがZ/(2^w)上で厳密三角、かつ内部座標について合同保存であるとする。各bitへ同じBoolean補正器Nを適用し、H(v)=F(v) XOR N(v XOR F(v))とする。Nは全128個のBoolean三角FでB回以内に正しい固定点へ到達するものを全数検査で選ぶ。

**収束の論証**：厳密三角Fには前方代入で求まる唯一の固定点rがある。sの下位k bitがrと一致するなら、合同保存性からF(s)の下位k bitもF(r)=rと一致する。そこではe=0、N(0)=0なので以後不変。次のbitへの作用は、固定された下位bitをparameterとする3変数のBoolean厳密三角写像となる。合同保存性により上位bitに依存しない。その唯一の固定点はrの次のbitであり、Nの普遍性からB回以内に到達する。k=0からの帰納法によりwB回で全て正しい。N3の全128関数で確認したB=4に対し、i32では128回となる。これは各回の単調な2進距離収縮や、H^Bの全域Lipschitz収縮を主張しない。

Fに内部rotate、右shift、比較等がある場合は仮定外。入力parameter自体の任意演算は固定して扱える。3bitの全数検証を32bit全状態の列挙と混同しない。証明候補をモデル検査と実Wasmで確認する。

Boolean版の8状態列挙解析は、内部加算・乗算のcarryがある32bit成分には直接適用できない。一方、bitごとの固定点消去、公開traceからの演算合成、SMTによる唯一解回復が対抗候補。小成分に単にcarryを加えただけで保護成功とはしない。

既存の有限環残差法との差分候補は、mod 2で下三角行列を選ぶことから、複数回の普遍Boolean補正を合成・持上げすることへの変更。特許の新規性・非自明性は未確認。既知の多段反復、relaxation、非線形preconditioning、自己安定化との先行比較が必要。性能が悪く、公開traceからFが容易に戻る場合は主案に採用しない。

## 実測結果

`boolean-feedback-word-v1`に3関数（乗算後加算、平方後減算、加算とXOR）、3初期値、plain/pipeline/feedback、raw/O3を保存した。42binary、535境界・4,096乱数入力/対象、合計194,502呼出しで不一致0。2bitでは全入力64×全初期状態64、3/4/8/32bitでは各2,048乱数条件を別モデルで検査し、合計36,864条件が上限内に収束した。有限テストを32bit全状態の列挙とはしない。

公開Wasmのloopを1回分の式へ読み、元F候補を部分式から列挙する`word-attack.py`を作成した。ランダムprobeは候補の足切りにだけ使用し、合格はH=F XOR N(s XOR F)の厳密なBoolean多項式一致で決める。加算・乗算は独立した不透明なatomとして扱うため、恒等式判定は十分条件であり完全な算術判定器ではない。Fの厳密三角性・合同保存性とround下限を確認して通常のWasmへ戻す。

raw/O3全6条件で回復した。解析時間26.47–36.86ms、読取り18.69–23.03ms、出力生成45.22–46.95ms。これらは別計測の単回値。先行smokeの約85msは出力生成も含む古い計測なので比較表から除外した。回復12binaryで55,572呼出し一致、元対回復6モデルはSMT UNSAT。追加監査は6byte再現、独立WABT72呼出し、短すぎるroundと内部rotateの拒否、恒等式の1bit改変の不一致確認。

## 分かった限界

carryを導入するとbitwise成分の8状態列挙をそのまま使えないが、それだけでは保護に足りなかった。元の加算・乗算が公開式の部分木に残ることが別の回復経路になった。3bitの普遍性分類や非共役性は構成の性質であり、解析耐性の証明ではない。今回の失敗から全ての非線形補正方式が弱いとは結論しない。
