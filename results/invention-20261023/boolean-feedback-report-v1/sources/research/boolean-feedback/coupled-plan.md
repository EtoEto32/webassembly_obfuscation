# 任意切替に耐える補正器で部分系を相互に結ぶ仮説

2026-10-23、実験前固定。Boolean残差候補の第3設計段階であり、別原理の第4候補とは数えない。前段階の小SCC消去を受けた改良。暗号鍵・秘匿された生成情報・解析不能性を前提にしない。

## 核となる条件

各Nが単独で有限収束しても、任意切替の安全性は従わない。N3と零補正器はそれぞれ普遍的に収束するが、ある三角Fで切替により0→1→0の循環が可能。全128個のFについて、複数補正器による遷移の和集合から正しい固定点以外のcycleが無いことを検査し、各状態の最大残りstepを証明用rankとして保存する。これなら各時刻・各bitで任意の補正器を選んでも所定回数で収束する。

元Fを順序付いた最大3座標の群へ分ける。群内部のFはbitwiseかつ厳密三角とする。群より前の値が固定されればFの外部入力は固定する。一方、補正器を選ぶmaskは群より後の変動中の状態やそのrotateから計算してよい。任意切替certificateがこの変動を吸収する。群ごとの最悪回数の和で全体の正答を保証する。maskを元Fの引数に入れるのではなく、同じ固定点へ向かう更新則の選択にだけ使う点を区別する。

## 検証する効果

前段階は公開依存graphから3以下のSCCを直接抽出できた。後続stateによるmaskで前段にも逆向き依存を作り、この分割を失わせる。ただしSCCが大きいだけで解析成功とはしない。元F、群境界、選択関数を渡さず、公開Hから小さな意味上の群を探索して復元する適応解析を試す。変換前・固定補正・切替補正を同じ評価器・同じ入力で比較する。

失敗条件：小群の探索やselectorの除去で容易に回復する、実行費用増に釣り合わない、switchingの既存理論の単純応用以上の差が説明できない。成功を先に仮定しない。

## 近接技術と暫定位置付け

切替Boolean networkの安定性それ自体は既知。Li/PangのAutomatica論文 DOI[10.1016/j.automatica.2023.111340](https://doi.org/10.1016/j.automatica.2023.111340)は任意切替と結合graph条件を扱う（出版社要旨・導入を確認）。F. F. LiのNeurocomputing133:63–66、2014、DOI[10.1016/j.neucom.2013.11.031](https://doi.org/10.1016/j.neucom.2013.11.031)はswitching-incidence matrixによる判定を扱う（出版社要旨・導入を確認）。ここでの8状態graph検査を新定理としない。

差分の検討対象は、全ての三角Fに対して共通に使える残差補正器族の選択と、元の依存順序を越えてselectorを接続するcompiler構成。その新規性・非自明性は未確立。Wasmの32bit bitwise演算と一定回数loopで実装するが、他言語でも可能でありWasm限定の新原理ではない。
