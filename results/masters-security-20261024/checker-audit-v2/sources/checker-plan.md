# Bの別実装による上界検査

2026-10-24。第三者libraryでの適用不足を受け、命令対応を無制限に増やす前に既存の安全条件を別経路で検査する。既存解析器はWABTのfolded WATと式木を使う。追試は実binaryのcode sectionとoperand stackから独立に書込み式を導出する。

対象は既存acyclic-v1の限定subset。未知命令・非共有memory32以外・解析不能なアドレスは、部分要約を検証済みとしない。実binaryのvalidationは標準WABTへ委ねる。別実装も機械検証済みではなく、小さなtrusted kernelの形式証明を達成したとは扱わない。

照合対象は固定したcompiler-v2、effects-audit-v1、library-v1の保存済みbinary。部分要約について、別導出した各書込み式が提示された集合に含まれることを要求する。式同値性の一般解法は用いず、構造が異なるが同値の上界を誤って拒否することはあり得る。全コピーは型・メモリ契約を確認した上で別に分類する。

部分要約の書込みを一つずつ削る・offset/lengthを変える・別hashを付ける等の改変を検査する。構造上の改変検出は、改変後の全要約が意味論的に不健全である証明ではない。range式の重複や包含があれば保守的に拒否する場合もある。

検査時間、受理率、偽要約の拒否、実装規模を報告する。既知のtranslation validation/proof-carrying codeに対する新原理と主張しない。既存解析器を再呼出しする方式とは分ける。
