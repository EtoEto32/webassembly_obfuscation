# 同じ出力課題での一般SMT条件合成との比較

2026-10-24、実装前。過去のCHC比較は具体storeでの反例到達性を判定した。Kの初期store条件を出す機能の比較としては出力が揃っていなかった。そこで同じ限定model・契約・任意API列について、一般的なSMT式のWP反復と量化消去で初期条件そのものを出す対照を自作する。

対照はKの等式lattice・copy写像・canonicalization・条件結果を使わない。共有parserから得た命令を別array意味論で実行し、後続の一般SMT式を置換する。内部host入力をForAllで束縛し、Z3の一般的な量化消去を適用する。反復の等価性もtyped domainのSMT queryで判定する。収束後にKとの式の差を検査する。

これはWhisk/PSyCO/WasmVerifierの著者実装の追試ではない。既知のWP・量化消去の自作baselineである。まずimport対照256契約を1回ずつ試し、同じ初期条件を出せるか確認する。timeout・unknown・反復上限・式の不一致を別記する。最初の1回の経過時間を正式性能比較とはしない。

対照が同じ条件を生成できれば、「Kだけが条件を出せる」という能力上の主張を棄却する。次に性能を比較する価値がある場合に限って、準備費用・複数process・反復・メモリを揃える。対照を意図的に弱めたり、具体state判定だけに戻したりして優位を主張しない。
