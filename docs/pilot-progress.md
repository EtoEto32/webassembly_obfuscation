# 予備実験の進捗

この文書は、作業途中の状況を記録したものである。予備実験完了後の確定値はpilot-report.mdを参照する。

## 2026-10-05 開始

- 開始時点では研究計画と申込下書きだけがあり、実験はまだ行っていなかった。
- 依頼文の`webassembly\_obfuscation`にあるバックスラッシュは、文字のエスケープ用と解釈した。作業には、実在する`webassembly_obfuscation`フォルダを使用した。
- Python 3.9、Node 24.15、Rust 1.97 nightlyを確認した。別途、同梱のPython 3.12.14も利用できる。
- サンドボックスからDockerとWSLへのアクセスは拒否された。重い環境構築に依存せず、公開データとWindows用ツールを優先する。
- 通常のサンドボックスからは、ソケットへのアクセスを拒否され、GitHubのファイルを取得できなかった。承認を得たネットワーク実行では取得できた。
- wasm-obf v1.0の未最適化アーカイブは6,138,192,724 bytes。HTTP RangeでZIPの一部を読み取り、必要なファイルを取得する方針とした。
- 代替手順として、通常版と制御フロー平坦化が確認された版に、同じWasm最適化を行う方法を優先した。元のコンパイル時の最適化条件による効果とは区別する。

## 2026-10-06 主目的の修正

- ユーザーから「マルウェアの難読化のトレンド等の分析」が意図であると指摘された。検出性能評価を主目的として続けない。
- 公開wasm-obfから、通常アプリ12本の通常版とTigress平坦化版、JS/HTMLなど、計84ファイルを取得した。取得セッション16655が正常に終了したことも確認した。これらは、実際に収集されたマルウェアのファイルではない。
- WABT 1.0.42とBinaryen 133の展開およびtool-downloads.jsonの存在を確認。研究用の解析環境として再利用できる。
- 今後は、候補となるマルウェアデータの出典と生成・加工履歴、悪性と判断する根拠、実際に収集したものか研究用に生成したものか、観測日時、重複、同じコードから派生したファイルの関係を確認する。
- 時系列のトレンド分析には比較可能な時期情報が必要。必要な情報がデータに含まれていなければ、その不足を予備調査の結果として明記する。
- 研究計画の冒頭に修正方針を記載した。旧申込下書きには、今回の主目的は反映していない。
