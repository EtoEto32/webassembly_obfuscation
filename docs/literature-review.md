# 公開データセットの比較・調査

先行研究と対象候補

調査基準日：2026-10-06。主要な原著論文、公開成果物、引用関係を一通り調べ、予備実験の対象候補25件を確定した。
「先行研究が存在しない」「世界初」「全公開データセットを網羅した」は現段階では主張しない。

## 調査手順と採用基準

1. WasmBench、WasmMal/WasmGuard、SWAMPED、Cryptic Bytesを起点に、著者論文、配布リポジトリ、リリース、参考文献・関連論文を追う。
2. Web検索で公開データセット、難読化、悪性ファイル、関連手法の名称を照合する。検索語は `search-log.csv` に残す。検索結果の二次記事だけで採用・新規性の判断をしない。
3. 配布物の一次情報、取得可能性、利用条件、実際のWasmの有無、実際に収集したものか、生成したものかを示す根拠を確認する。論文中の実験件数と公開配布件数を別に記録する。
4. マルウェアラベル付きデータセットを主対象、一般Wasmデータセットを比較対象、生成された難読化データセットを対照とする。脆弱性テスト、採掘プログラム、指紋採取を無条件にマルウェアとしない。
5. 採用した版・配布物の全対象を解析する。一般比較のWasmBenchは著者のfiltered v1.0全体を対象とし、raw収集全体とは区別する。JS埋め込みと入れ子アーカイブは独立した取得範囲として明示する。
6. 主要一次論文の参考文献と引用検索を一巡し、25候補で対象を確定した。取得不能は除外理由と試行を残した。

公開コードのライセンスが、同梱された第三者由来のファイルの再配布権まで保証するとは解釈しない。解析結果・ハッシュと、取得したバイナリを分離して保存する。

## 新規性の現在の評価

既存研究に、大規模実態調査、難読化の横断的な技術評価、元ファイルのハッシュ照合がある。したがって「多数のWasmを解析した」「ハッシュで原本を探した」だけでは既存研究との違いが小さい。

検証する貢献候補は、複数の公開配布物を同じ単位で照合し、(1) 実際に収集したもの、生成したもの、計測用に変換したもの、重複して保存されたものの割合、(2) 実際のファイルで根拠を確認した難読化、(3) これらの区別で特徴分布がどう変わるか、を再現可能な形で示すことである。既存研究との違いと実測の両方が揃うまで、新規性を確定しない。
