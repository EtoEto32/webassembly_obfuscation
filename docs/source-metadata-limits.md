# 公開メタデータの日時と利用条件の確認

調査基準日2026-10-06。確認対象の版とファイルを固定して調べた結果であり、すべての公開情報を調べ尽くしたものではない。

## 時系列の解釈

今回取得できた次の情報だけでは、Wasmマルウェアの難読化について、各バイナリの観測日を根拠に基づいて特定し、時期ごとに比較できる時系列を作ることはできない。

|対象|実際に確認したメタデータ|時系列へ使える範囲|
|---|---|---|
|WasmMal|train 12,018行・test 3,006行のCSV。各行はファイル名と著者ラベルだけ|観測日や各ファイルの生成元の日付はない。論文年を悪性ラベルの7,512ファイルの出現年にしない|
|WasmBench filtered v1.0|8,461モジュール、13,340出典ファイルのメタデータ。取得済み8,460 SHAをすべてカバー|調べた出典フィールドには観測日時がない。公開Git版とリリース版のJSON内容も同一ではないため、実際に取得したリリース版を基準にした|
|Wasmizer Figshare v2|8,915件の`.meta`と同梱README|READMEに2022年12月の収集とあるが、個別の出現・観測日時はない。収集月を各バイナリの初出月にはできない|
|MinerRay|29サイトの結果例CSV、901行のサイト一覧CSV|ヘッダに観測日とバイナリSHAの列がない。利用者への告知等のサイト情報はあるが、この2ファイルだけでは、各ファイルの観測日を対応付けた時系列を作れない|
|Industry2025|取得したvalidwasm.7zの通常のファイル4,606件がすべてWasmファイル|この配布内には観測日を対応付ける別ファイルがない。論文のurlscan等の観測記録を本実験では再構成していない|

機械可読結果は`results/provenance/observation-dates-partial.json`。残りのデータセットも含め、関連するメタデータが一切ないと証明したわけではない。生成された対照プログラム、計測用に変換されたコピー、公開日の異なる同じバイト列を年代別に数える際に、独立した攻撃事例のファイルとして扱わない。ZIP/7zの更新日時、Gitのコミット日時、本実験のダウンロード日時も実環境での初出日時に置き換えない。

したがって予備実験の結論は、公開版内の特徴の分布や公開版同士の違いと、ファイルの出典・生成履歴の影響に限る。時間変化を次の実験にする場合には、観測日時・URL・その時点のバイナリSHAを同時に保存し、同じ収集方法で複数時点を比較する設計が必要になる。

## 利用条件の明示状況

版を固定したGitのファイル構成、保存済みのルートディレクトリのLICENSE、著者のREADME、配布記録を確認した。25候補の監査結果を`results/catalog/license-metadata-audit.json`へ保存した。うち18候補でバイナリを取得している。以下は、利用条件がどこに明記されているかを記録したものである。すべてのファイルの利用許諾や権利を個別に確認したという意味ではない。

|配布物|確認できた利用条件の記載|適用範囲について未確認の点|
|---|---|---|
|WasmMal|ルートディレクトリのLICENSEはApache-2.0|第三者由来の全ファイルへの適用を独立には確定していない|
|SWAMPED、deepMiner|ルートディレクトリのLICENSEはMIT|同梱する第三者由来のファイルを含めた権利の保証とはしない|
|WasmBench|ルートディレクトリのLICENSEはMIT。READMEは著者の収集・解析コードにMITが適用されると説明|収集バイナリの所有権を主張しないと明記。コードのMITと各バイナリの条件を区別する|
|Wasmizer|ツールのルートディレクトリのLICENSEはMIT。Figshare配布記録はCC BY 4.0|各第三者バイナリの条件は独立には確定していない|
|AndroWasm|Zenodo配布記録はCC BY 4.0|配布記録に記載された条件として保存する|
|Proof-of-Theft|Zenodo配布記録はCC BY 4.0。配布物の説明文書の§5はGPL version 2|異なる利用条件を両方記録し、同じ範囲に適用されるとは判断しない。説明論文自体のCC BYと配布ソフトウェアの条件も区別する|
|Cryptic Bytes、Diversification、WASim|依存物等のサブディレクトリにLICENSEあり。版を固定したファイル構成では、ルートディレクトリのLICENSEは未確認|依存するソフトウェアの利用条件を、データセット全体に適用しない|
|MinerRay、SEISMIC、WASMixer、Wobfuscator、WBD|版を固定したファイル構成では、ルートディレクトリのLICENSEを確認できない|今回の確認範囲での明示状況。権利が存在しないという意味ではない|
|Industry2025|ダウンロードしたアーカイブはWasmのみ|アーカイブ全体の利用条件をこの内容からは確認できない|
|MineSweeper|固定コミットのルートディレクトリのLICENSEはApache-2.0|外部の収集TARと各第三者由来のファイルへの適用を独立には確定していない|
|Wasm-R3 OOPSLA_2024|使用した固定ブランチのルートディレクトリのLICENSEを確認できない|現在のmainブランチのMIT宣言を、過去の配布版へ自動適用しない|

Proof-of-Theftの宣言は[著者の配布物の説明文書の§5](https://drops.dagstuhl.de/storage/05darts/darts-vol012/darts-vol012-issue001_ecoop2026/DARTS.12.1.19/DARTS.12.1.19.pdf)と[Zenodo配布記録](https://zenodo.org/records/18496931)を別々に参照した。説明には、先行手法の比較実装の一部は利用条件のため配布しないことも記されている。論文の評価対象と公開されているファイルの範囲が一致するとは仮定しない。

本作業で作成する成果物は測定コード、ハッシュ・出典・特徴量、図表、解析記録とする。取得した第三者バイナリはローカルの`data/`にあり、ソース管理から除外している。公開する研究成果から元のバイナリを取得できるように、配布元と固定版の情報を残す。ライセンスが未確認の項目を、「利用条件確認済み」とは記録しない。

## 再現

```powershell
.venv\Scripts\python.exe scripts/fetch_supporting_metadata.py
.venv\Scripts\python.exe scripts/audit_observation_dates.py
.venv\Scripts\python.exe scripts/audit_license_metadata.py
```

最初のコマンドは、固定コミットのMinerRay CSV2件、WasmizerとMineSweeperのLICENSEを取得し、Git blob SHA-1・SHA-256を検証する。Proof-of-TheftとMineSweeperの本文PDF等は`audit_literature_sources.py`で取得し、pypdfのある環境で本文を抽出する。各ファイルのURL・SHAを取得記録に保存した。
