# 草稿追補：非単射な状態表現は線形な入出力の同定を妨げない

## Abstract

Wasmの持続する整数状態を非単射な表現へ移し、元の全状態へ戻すdecoderを必要としない更新を生成した。正48条件807,024 stepと6,816 resetで挙動が一致したが、全24保護・対照条件の入出力規則を各16応答で回復できた。零因子を含む有限環上でも、低次数の線形系という外部の性質が既存の漸化式合成を可能にする。独立した新規性と追加保護効果を確立した結果ではない。

## Introduction / Related Work / Motivation

一時的な格納領域の重なりが到達定義解析で消えたことから、複数呼出しにまたがる状態と非単射な表現を検討した。通常の体上の逆元が使えない場合でも、合成数modulusの漸化式合成はReeds–Sloane (1985)に先行する。[文献確認の範囲](prior-art.md)を参照。有限環上の状態空間研究についてはNappほか(2022)の要旨だけを確認し、本文の具体構成は未確認とする。

## Threat Model / Proposed Method

公開binaryと方式を知り、公開APIへ任意入力を送れる解析者を想定する。x'=Ax+Bu,y=Cx'に対し、D=diag(2^s_i)の核をAが保ちCが消す条件を確認し、z=UDxを生成する。Uは可逆だがDは一般に非可逆である。到達像上で零になるKを追加するアブレーションも行った。行列恒等式が、初期化・更新・観測の関係を保存する。

## Implementation / Evaluation

実際の.wasmを読むPython変換器、WABT1.0.42、Binaryen133、Node24.15.0を使用した。状態2/3/4は同じ線形系族の設定であり独立アプリではない。非単射版の実行時間は元版の約1.03–1.09倍。3 fresh process×7batch、16,384 stepのwarmupを行った。

回復器は内部state・source行列・生成manifestを使わず、16応答から合同式を解いた。全24条件の応答列と回復次数は対照と変わらなかった。合同式fitの31反復中央値は約0.079–0.230ms。零因子を持つpivotを含み、mod2/4の小系の全列挙とmod8/16の乱数系を合わせ5,184系で検査した。さらに全24バイナリの線形性等の前提を別の記号実行で確認し、WABTでも384 stepが一致した。[詳細](../../results/invention-20261022/torsion-state-report-v1/comparison.md)。

## Discussion / Limitations / Conclusion

非単射性は、全内部状態の一意復元を防ぐ。しかし、それと同等な外部計算の回復費用は別である。低次数線形系は有限環上でも有理級数を持ち、既知上限Nのもとで2Nの応答一致から同等の漸化式を構成できる。これは既知の数学からの直接的な議論であり、新理論とは主張しない。

前提を外した非線形例外と遅延17の反例は、16応答だけでは同値性を保証できないことも示した。任意Wasmの解除や元状態の復号を実現したとは扱わない。具体的な生成規則は保存するが、独立した主発明としては不採用とする。
