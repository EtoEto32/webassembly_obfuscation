# 累積上界の追加監査計画

2026-10-24、probe-v2後に固定。

1. 元7例以外に、同じmarker列を持つ分岐を固定seedで生成する。秘密bitによる全分岐選択と複数payloadについて、独立interpreterと実Wasmを照合する。変換後O3も検証する。
2. 全分岐が同じ条件を共有するケースを作り、構造要約の過大評価を測る。構造解析がsemantic path feasibilityを解くとは主張しない。
3. 上界を1減らす改変、持越しcreditを捨てる誤実装、秘密に応じた返金が何を壊すか、単純な実行可能反例を保存する。これらを提案の安全性を突破したin-model攻撃とは数えず、必要条件の負例とする。
4. 公開markerで予算を変更する、公開履歴だけに依存する決定的なpolicyを試す。現在の初期予算固定試験より強いobserverだが、時間による割込み・再入は対象外。
5. 独立checkerはまだない。現段階のhashは再現用で、偽のboundに対する検証証明と表現しない。
