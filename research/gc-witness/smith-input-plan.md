# R追加試験: 実生成moduleへの参照引数

2026-10-27、実行前の計画。smith-v2の同一502生成binaryを再利用する。関数本体・計数器を変えず、呼出し側だけを変更する。nullのみの実行では入力の非null分岐・要素アクセスに届かない可能性がある。

候補入力: null、空array、element 0を通る長さ1/2/4の参照鎖。Rの既存生成器を非null参照を返すprovider moduleに拡張し、Wasm同士のimport/export経由で型を保持して渡す。scalar arrayは参照鎖を持たないので長さ1/2/4のゼロ値arrayを単純対照として使う。構築不能な自己参照structはnullのみ。各呼出しはfresh instance、fuel 100,000、同じ制限下で行う。全成功counterは対象module内の操作だけを数える。

これは固定された深さ候補の探索であり、プログラムから必要な入力を解く新しいアルゴリズムではない。今回、複雑な需要解析より先にこの単純対照を試す。生成器のsmall patchと入力供給を混同しない。同じbinary内のnull/empty/depthを比較し、成功アクセスを持つbinaryの数と、空arrayから増えたbinaryを測る。単に実行回数が多い群との総件数比較はしない。

計測器校正用に手書きの深さ1/2/4のアクセス関数も使用する。校正での成功をランダム生成器のcoverage改善と合算しない。alias・広い添字・scalar値・callback意味は今回の対象外。
