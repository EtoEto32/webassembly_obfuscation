# 値から配置を再構成するブロック表現：事前仮説

2026-10-22。root-descentの次区間。前区間は実測集計・出典照合・反証の記録を完了したprogressである。本案は反復による計算難化から、private memoryの動的なフィールド配置へ方向を変える。

4語のブロックxについて、回転に不変な統計量s(x)=Σh(x_i) mod4を求め、語をs(x)位置右へ回転したyを保存する。h(t)=(t xor (t>>13)) mod4とする。s(y)=s(x)なので別の配置表を必要とせず、元の語iはy[(i+s(y)) mod4]にある。語をoldからnewへ更新すると、回転量の変化はΔ=h(new)-h(old) mod4。更新した物理ブロックをΔだけ回転すれば新しい表現になる。全ブロックを元の配置へ戻す必要がない。

この初等的な不変量・群作用の関係や、データ依存符号化一般を発明とは呼ばない。US9906360B2のdynamic permutation / block data protection、Practical Data Location Obfuscationが近い既存技術。検討する差分は、配置情報をデータ自身から回復し局所差分で移送する具体的な生成規則である。Wasmのv128.swizzle、固定ページ境界、拡張した有効アドレス計算を使うが、他形式にも実装可能。

比較はplain、fixed（固定1語回転）、full（同じ動的表現を全体復号・更新・再符号化）、transport（差分だけ回転）、bad（更新後の回転を省く負対照）。fullとtransportは全く同じ境界表現であり、計算手順のみが異なる。

実Wasmの制限を明示して変換し、戻り値・trap・復号した全メモリ・継続呼出しを比較する。小語長で表現と更新を全探索する。raw/O3双方に対し、配布binaryのhelperを意味的に同定し通常配置へ戻す方式既知攻撃を試す。helperの有限照合だけを任意Wasmの同値証明とはしない。固定配置に対して解析費用が増えるかと、fullに対する更新費用の改善を分けて測る。

最大のReject理由は、既存の動的配置の単純な特殊例であり、公開統計量を辿る解析も同じくらい安いこと。単に固定オフセットが消えたこと、他の逆コンパイラがSIMD未対応であることは成功条件にしない。
