# 論文追補：公開された逆変換の除去と行列式の直接回復

## Abstract

入力依存の混合手順を生成時に消去し、純粋なi32計算全体を多項式行列の行列式へ移す候補を検査した。単元小行列の不変条件によって、偶数・零の出力を含め、32bit環上で奇数pivotだけを用いた評価を可能にした。実Wasmの正42条件214,032呼出しは一致したが、方式既知の解析は18条件全てを短い等価式へ回復した。近い先行技術の存在と費用評価から、独立した新しい難読化原理としては採用しない。

## Motivation / Method / Implementation

前の再帰混合案では、現在の小さな混合行列が履歴を十分に要約していた。本候補は、その行列や逆行列を実行時に渡す構成を使わず、式全体をpath-sum、bordered matrix、生成時の多項式行・列操作へ変換する。WABTを用いた限定バイナリ変換と、公開係数表を評価するWasmを実装した。[構成と正しさ](algorithm.md)に述べるように、出力が非単元でも最後以外に奇数pivotが存在する。

## Related Work / Threat Model

全計算の行列式表現にはADP、入力依存の多項式行・列混合にはEP2831791B1の直接的な先行記載がある。[実読範囲](prior-art.md)を限定し、既知の原理を新しいものと数えない。方式既知の解析者には全Wasmを与え、生成ログや元式は与えない。目標は実行可能な短い等価算術式の回復であり、sourceの変数名や因数分解をそのまま戻すことではない。

## Evaluation

3種の小式、3行列モード、raw/O3を評価した。回復器は公開係数の8通りのparity評価から全入力に対するrank条件を確認し、列集合を状態とするdivision-freeな記号計算で全行列式を得た。全18条件を回復し、独立BigInt oracleと別WABT実行器を含む正当性検査が一致した。負6条件、profile拒否、rank不足も別に検査した。

同じ操作列の定数混合に対して、入力依存混合は解析本体を約8.06–15.24倍、読取・証明込みの中央値和を約1.36–1.77倍に増やした。実行は約2.85–3.09倍、未変換比では約508–965倍だった。したがって解析費用増を否定する結果ではないが、小例で数msの計算によって変換全体を除去できた。詳細な実測条件・ばらつきは[比較表](../../results/invention-20261022/unit-minor-report-v1/comparison.md)に示す。

## Discussion / Limitations / Conclusion

局所逆変換を公開しないことだけでは、公開された全体の保存量を計算する解析を防げなかった。ここでは元式が低次数の少数変数多項式であるため、行列式の展開後に多くの項が相殺した。巨大行列、変数数や次数が大きい場合へこの成功率や時間を外挿しない。汎用逆コンパイラや人間の作業時間、同じ実行費用に調整した他方式は未評価である。

正当性を保つWasm変換と適応的解析の実装は成果として残す。一方、既存の行列式・多項式混合から独立した新規性と、実用的に優れた保護効果は未確立であり、主発明に採用しない。次の設計では、公開状態の小さな逆変換だけでなく、出力関数全体の直接正規化が安価かを事前に調べる必要がある。
