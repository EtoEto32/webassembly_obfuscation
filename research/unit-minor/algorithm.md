# 生成規則、意味保存、回復

対象は純粋な3引数i32→i32のadd/sub/mul式。任意の定数と全32bit入力を認める。制御フロー、localへの代入、メモリ、import、table、GC、浮動小数点、除算、例外は入力profile外として拒否する。デバッグ情報の保存は契約に含めない。出力はrunのみをexportし、非公開memory 2pageを使う。逐次呼出しを対象とする。

## 変換

1. 実WasmをWABTで検証・逆アセンブルし、対応する式を読む。
2. leafをラベル付き辺、加算を並列接続、乗算を直列接続にして非循環のalgebraic branching programを作る。減算は片方の枝を負にする。
3. 頂点をtopological順に並べ、隣接行列A、W=I-A、始点s・終点tを得る。
4. C=[[W,e_t],[-e_s^T,0]]を作る。
5. 異なる行または列への加算を、係数h(x,y,z)=奇数定数＋入力変数で繰り返す。行列要素の総次数3、係数数1,800という生成時上限を超える操作は採用しない。12N回試行する。定数対照は同じ採用操作列についてhをその定数項へ置き換える。
6. 全要素をZ/(2^32)上の多項式係数表へ展開してから出力する。混合操作列、左右の行列U,V、元の式はWasmに含めない。
7. 実行時は公開係数表から行列を作り、奇数pivotだけで消去する。最後の要素はそのまま積に掛ける。

```text
acc = 1
for k = 0 .. N-2:
    (i,j) = find_odd_entry(matrix[k:N, k:N])
    swap rows i,k and columns j,k; negate acc for each swap
    q = matrix[k,k]
    inv = 1
    repeat 5: inv = inv * (2 - q*inv) mod 2^32
    acc = acc*q
    for i > k:
        factor = matrix[i,k]*inv
        for j >= k: matrix[i,j] -= factor*matrix[k,j]
return acc * matrix[N-1,N-1] mod 2^32
```

## 正しさの根拠

Aは厳密上三角なのでW^-1=I+A+…+A^(n-1)、det W=1。W^-1の(s,t)要素は経路積の和fである。block determinantの恒等式からdet C=f。これは有限体に限らず、この可換環と単元Wで成立する。

行・列加算は入力の値によらず行列式を保存する。C mod 2にはW mod 2という可逆なN-1次小行列がありrank≥N-1。左右の可逆操作後もrankを保存する。奇数pivotは環の単元で、そのpivotを消去すると残りのmod 2 rankはちょうど1だけ減る。したがって最初のN-1回は奇数pivotを選べる。出力f自体が偶数または0でも、最後の1要素に除算をしないのでよい。

Newton逆元の誤差1-q*invは更新ごとに二乗される。奇数q、inv=1から5回で32bit分が一致する。全積・加減算のwraparoundはi32の意味と一致する。メモリは係数表・入力・行列で領域を分け、全行列要素を各呼出しで初期化し、外へexportしない。profile内では追加trapが生じない。

これは構成に関する数学的説明であり、Python/WABT/V8を含む実装全体の機械証明ではない。動作試験と別実行器の記録を別に保存する。

## 方式既知の回復

解析者はWasmのみと方式の知識を持つ。元式、seed、操作列、生成manifestは不要。既知kernelのraw/O3構造を照合し、active dataから係数表を読む。全8通りの入力parityでrank≥N-1を確認する。多項式のmod 2評価はparityだけに依存するため、この有限検査が全32bit入力でのpivot存在条件を保証する。単にkernelが一致するだけでは、改変された係数表がtrapする可能性を除けない。

回復器は列集合Sごとの部分行列式を動的計画法で作り、次の行から未使用列への積を符号付きで加える。割算を使わず係数をmod 2^32で正規化するため、非単元による除算失敗がない。最後に得られる多項式を通常のi32式に戻す。元のソースと同じ構文・最適な因数分解を得ることは目標にしない。

全体の計算量はこの実装では2^N個の列集合と中間多項式の項数に依存する。今回N=5,6、3変数、次数上限3であり、巨大な一般行列の解析についての結論ではない。公開係数から計算全体の保存量を直接求められるため、混合操作を逆算する必要がなかった。
