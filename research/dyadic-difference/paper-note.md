# 追補：Wasmの差分評価と有限環の短い等価代表

## Abstract

一変数i32多項式を32個の2進刻みの差分へ変換する難読化候補を実装した。元式を評価する関数を残さず、到達不能な入力で差分を乱す修正も行った。しかし有限環の既知の補間構造により、全18条件を公開34問い合わせで回復できた。新規な主方式としては採用しない。

## Introduction / Related Work / Motivation

明示的decoderを消すだけでは意味回復を防げないという前段の失敗を受け、計算値の符号化から差分だけの実行へ移した。有限差分化のPaige–Koenig、有限環多項式のGeelenほか、Singmasterの関連性と実際に読んだ範囲は[prior-art.md](prior-art.md)に示す。既存の数学を難読化という用途だけで新発見と扱わない。

## Threat Model / Proposed Method

解析者は方式と公開binaryを持ち、短い等価関数を生成する。元係数の一意回復は要求しない。生成器はD_i(y)=F(y+2^i)-F(y)を展開し、入力のbitに従って差分を累積する。修正版は有効prefixで0になる補正を加える。正当性と回復の疑似コードは[algorithm.md](algorithm.md)に記録した。

## Implementation / Evaluation

PythonとWABT/Binaryenを用いる限定binary変換器を作成した。初版の正30条件247,830呼出し、修正版36条件297,396呼出しで不一致0。別WABT、誤変換、byte再生成、狭い環の全入力検査を実施した。初版の全12条件は静的積分で回復。修正版はその解析器を6条件とも拒否させたが、公開34問い合わせによる等価回復が全18条件で成功した。

修正版の実行時間は元の約63–101倍、回復版は元と近い短いHorner式となった。性能の反復条件・ばらつき・memory・変換時間は[README.md](README.md)および生JSONを参照する。3例の合成多項式と、1種類の再帰式の3深さを実アプリ数として数えない。

## Discussion

形式係数が一意に戻らなくても、零多項式による差は出力を変えない。34!の2進付値から、次数を増やすだけではこの一変数関数classに小さな等価代表が残る。形式次数約100万の追加対照も同じ問い合わせ数で回復した。これは今回の発明ではなく、既知の構造が保護仮説を否定する具体例である。

## Limitations / Conclusion

問い合わせ攻撃は整数係数多項式関数というpromiseに依存し、範囲外の関数では誤る反例を示した。全入力のツール形式検証、任意Wasmへの一般化、実アプリでの効果は主張しない。実装と設計修正を保存する一方、独立した新規性と保護上の優位は確立できず主方式として不採用とする。
