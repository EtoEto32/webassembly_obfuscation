# 変更しないcopyが表現に課す制約

2026-10-19。候補の成立条件を絞るための補題。新規な数学的定理・難読化方式・特許性を確立したという主張ではない。

## 対象と命題

空でない値集合を A、セル数を N≥2、メモリ状態を x∈A^N とする。C(d←s) は宛先セル d だけを元の x_s で置換し、他を変更しない操作である。E:A^N→A^N は固定した全域の表現写像とする。

すべての d,s と x に対して

    E(C(d←s)(x)) = C(d←s)(E(x))                           (1)

が成立する必要十分条件は、位置によらない同じ写像 π:A→A が存在して

    E(x)_i = π(x_i)   （すべての x,i）                    (2)

となることである。E が全単射なら π も全単射。非線形な E も含み、線形性を仮定しない。

## 証明

Δ(a)=(a,…,a) と置く。Δ(a) はすべての C の不動点なので、(1) により E(Δ(a)) もすべての C の不動点になる。そのような状態は全座標が等しい。したがって一意な π(a) により E(Δ(a))=Δ(π(a)) と書ける。

任意の座標 j に対して、セル j を他の各セルへ順にcopyする操作列 B_j を取る。元セル j を上書きしなければ B_j(x)=Δ(x_j)。E は個々のcopyと可換なので、その合成 B_j とも可換である。よって

    Δ(π(x_j)) = E(B_j(x)) = B_j(E(x)) = Δ(E(x)_j).

j 座標を比較して E(x)_j=π(x_j) を得る。逆に (2) であれば、copyの前後どちらで π を適用しても各座標の結果は同じで、(1) が成立する。

E が単射なのに π(a)=π(b), a≠b とすると E(Δ(a))=E(Δ(b)) となり矛盾する。E が全射なら、任意の b に対する Δ(b) の逆像の各座標から π の全射性が従う。逆方向も成り立つ。□

## Wasmへの対応

1メモリ内の任意の有効な `memory.copy(d,s,1)` が (1) の各操作を実現する。したがって、全状態で正しく、同じアドレス・長さのcopyを変更せず実行し、前後の追加修復も行わない表現変換は、上の必要条件を満たす必要がある。

十分性も任意長のcopyについて成立する。重なりを含むcopyは、元のソース区間の値を宛先へ移すので、同一 π の適用と順序を交換できる。固定した同じサイズのメモリなら境界違反の条件も同じで、trap前にメモリが変わらない。ゼロ長でも境界検査が先に行われる。[Wasm 3.0 実行仕様](https://webassembly.github.io/spec/core/exec/instructions.html#exec-memory-copy)を確認した。

これは以下の条件に限る。

- 同じサイズの全状態空間 A^N に対する固定表現。到達可能状態だけの関係を扱う命題ではない。
- copyの実引数を変えず、その前後に補正処理を入れない。
- 表現を表す別のメモリ・metadata・時変の鍵状態・履歴を使わない。
- 並行アクセスのない1メモリ。共有メモリ・memory64・多メモリ・growを今回の実装は扱わない。

メモリ難読化全般の不可能性ではない。また、任意のcopy引数を受け取れるプログラムでも、実際の到達状態に対してしか正しさを要求しない場合には、全域仮定を別途示す必要がある。

## 条件を緩めた場合

**gセル単位**：長さ N が g の倍数で、すべてのcopyの始点と長さが g 境界なら、A^g を1要素とした同じ証明が使える。任意の整列ブロック間copyを許す場合、全ブロック共通の写像 Π:A^g→A^g が必要十分となる。ブロック内の混合は可能だが、ブロック間の混合は同じ全域条件の下では残らない。

実装の g=2 は `(a xor b)&1` が1なら二つを交換する involution である。交換条件が交換前後で不変なので、同じ操作が逆写像になる。1バイトcopyを許すと破れる。例えば x=(0,1,2,3), d=0,s=1,n=1 では E(C(x))=(1,1,3,2) だが C(E(x))=(0,0,3,2)。

**一方向だけのcopy**：2セルで C(1←0) だけを許すなら、全単射は

    E(a,b) = (π(a), ρ_a(b)), ρ_a(a)=π(a)

という形でよい。π と各 ρ_a は A の置換。証明：可換条件は E(a,a)=(E_0(a,b), E_0(a,b)) であり、第一成分は b に依存せず、対角状態も対角へ移る。有限集合上の全単射なら対角上の π と各行の ρ_a が置換となり、上式で全てを尽くす。|A|=3 なら 3!×(2!)^3=48 通り。双方向copyでは 3!=6 通りへ減る。例 E(a,b)=(a,2b−a mod 3) は一方向と可換だが、逆方向では破れる。この節の分類は有限 A を対象とする。

**変更しないfillも要求する場合**：任意の値 a による同じ全域fillと E が可換なら E(Δ(a))=Δ(a)。したがって copyの命題の下で π(a)=a、すなわち E は恒等写像に限られる。fillの入力値を符号化してよい場合にはこの追加制約は適用されない。この系は手計算の導出であり、今回のWasm実装はfillを含めていない。
