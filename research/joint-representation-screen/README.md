# 複数値の表現に進む前の反証検査

2026-10-18。直前のSIMD案は単一値の真偽射影で回復された。しかし「単一値から復元できない」を次案の成功条件にすると、既知の安い変数混合まで合格してしまう。以下はその反例であり、新しい難読化方式の提案ではない。

## 検査する仮説

棄却する推論は「各座標に元の値への写像が存在しない → 解析が高費用」である。ここで「存在しない」は全状態で同じ復元関数が使えないという厳密な意味。有限個の観測から写像が見つからない、という意味ではない。

環 R=Z/(2^w)、状態 (x,r)∈R² を考える。秘密鍵、外部秘密、暗号学的な仮定はない。

|対照|表現 E(x,r)=(a,b)|x の共同復元|復元の演算数|
|---|---|---|---|
|identity|(x,r)|a|0|
|線形な混合|(2x+r,x+r)|a−b|1|
|二段の二次更新|a=x+r²; b=r+a²|t=b−a²; x=a−t²|4|

演算数は剰余乗算・減算を各1回として手で数えたもの。解析器の探索費用や実行時間ではない。復元式を与えた検証であり、自動発見したと報告しない。

### 単一座標の復元が存在しないこと

w≥2 で、次の二つの元状態は指定座標が等しい一方、x が異なる。数はすべて R 上で読む。

|表現|a に対する反例|b に対する反例|
|---|---|---|
|線形|(0,0) と (1,−2)|(0,0) と (1,−1)|
|二次|(0,0) と (−1,1)|(0,0) と (−14,−4)|

二次の最後の状態は (a,b)=(2,0) に写る。−14 は w≥2 で零でない。したがって両座標について単独復元不能が成立する。それでも表の共同復元は幅に依存しない定数個の演算で済む。線形の場合 r=2b−a、二次の場合 r=b−a² であり、状態全体も戻せる。

これは「関係を使う方式は全て弱い」という定理ではない。単独復元不能という判定基準だけでは、追加の保護効果を示せないという反例である。既存の[観測文脈の合成実験](../observation-synthesis/README.md)も、複数観測値からの少数演算回復を検査していた。この基準を後退させない。

- 2/3/4/8bit、3表現の全状態を列挙：197,616組。共同復元の不一致0、全表現で全状態への単射を確認。
- 各表現の32bit境界49組＋固定seedのランダム4,096組：計12,435組、不一致0。
- 合計210,051組。線形・二次の各座標について異なる x の衝突反例を保存。

有限実験とは別に、上の式で全幅 w≥2 の反例と逆変換を説明している。Wasmバイナリ変換、最適化器比較、性能測定、人間の解析時間、第三者ツールの攻撃は今回実施していない。本検査を主方式の実証・新しい候補の数に算入しない。

## 特許を目指す際の判断

[公開特許・論文との照合](../patent/joint-relations.md)により、複数変数を同時に符号化する一般的な着想にも先行記載があることを確認した。次の具体的構成では、単一座標の射影の消失に加え、共同復元・境界復元・等価な計算の抽出に必要な費用を調べる。保護効果と先行技術との差は別々に判定し、全件回復だけを理由に不採用にしない。

今回の進捗は、誤った選定基準の反証と先行記載の追加確認。独立した新規性・実用的な保護効果を備えた主方式の確立は未達。
