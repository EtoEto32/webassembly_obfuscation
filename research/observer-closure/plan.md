# 非線形更新を有限精度の観測状態へ置き換える試験

2026-10-23。実装・測定前の固定計画。

対象は private i32 状態 x、reset(s)、peek()=x²、step(u): x←F(x)+u; return x²。F は次数2–4の整数多項式。全演算はmod 2^32、import・memory・trap・再入は対象外。実.wasmの限定profileを検証して変換する。

生成仮説：z_j=2^e_j x^j を状態とし、出力z_2から開始する。z_jの更新を展開し、係数の2進付値から必要なe_kを小さくするworklistを閉じる。係数が2^32で消える高次項は保持しない。閉包が得られれば、元のxを保存せず、入力に関して多項式・観測状態に関して線形の更新が生成できる。閉包を人手で選ばない点が過去のsymmetric-state/torsion-stateとの実装上の差。ただしobservable realization、Carleman lifting、有限環多項式の既知理論から独立した発明とはまだ認定しない。

比較は元・full（e_1=0を強制）・quotient（出力から必要な精度だけ生成）。反証対照はquotientで一次座標の寄与を不当に除くbad。3つの人工F、raw/O3、実際の連続API呼出しを検査する。

最優先攻撃は方式既知の選択入力：reset(s)後のstep(1)とstep(0)の差から2F(s)を取り出す。Fの次数上限4のみ既知として、5点・10stepクエリからmod2^31の多項式を復元する。元F・変換係数・seed・manifestは攻撃へ渡さない。成功時は単一i32状態の同等Wasmを出力する。APIのreset能力は明示的な攻撃条件であり、reset不可の一般プログラムへ結果を拡張しない。

成功条件は(1)全テスト一致、(2)通常最適化後も攻撃者が元と同程度の短い更新へ容易に戻せず、(3)fullと比較してquotientの費用に見合う保護差があること。10クエリ復元が成立すれば、このprofileは主特許候補へ昇格しない。原状態の非一意性だけを保護効果と呼ばない。

正当性はNode差分、別エンジンWABT、小幅の全状態・全入力、閉包係数等式で確認。性能は同一Wasm loop、3 fresh process×7 batch、ウォームアップと校正、サイズ・変換時間・linear memory・process RSSを記録。数学的な閉包証明と実装検査を区別する。
