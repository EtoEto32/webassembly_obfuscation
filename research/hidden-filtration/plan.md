# 座標対応を消した有限回更新系：実験前の設計

2026-10-23。研究継続。新規性は未確立。今回の優先順位は、既知の座標変換の再実装を新発明と呼ばず、その限界を超える具体規則があるかを検証すること。

## 先に除外した一般主張

Paul Marion Hriljac, [WO2012040383A1, Systems and methods of source software code obfuscation](https://patents.google.com/patent/WO2012040383A1/en)、優先日表示2010-09-24、公開2012-03-29。書誌、説明0048–0057、0078–0086を読んだ。可逆な線形・非線形変換の合成、三角多項式の生成、合成式の展開・簡約、入出力や状態更新の書換えが具体的に記載される。単に非線形化・逆変換のinline化をすることは独立した差分ではない。請求項全体や法的状態は評価していない。

## 核になる限定仮説

元Wasmのpureな式DAGから、各節点が1段前の値だけを読む同時更新F_xを生成する。入力xを固定すると、DAG深さD回で、任意の初期stateから正しい全節点値へ到達する。最終出力座標を保存する全単射Eを選び、H_x=E F_x E^-1を展開して配布する。実行時はHだけをD回評価して出力座標を返す。E/E^-1、元DAG、生成seedは配布しない。初期stateの符号化も、出力の復号も不要になる。

これは有限環残差法とは違い、2進精度を徐々に上げない。ただし有限回収束と共役という数学自体も既知で、組み合わせただけなら主発明にしない。

比較は元版、無混合の同時更新、線形混合、非線形混合。非線形では、全ての非零なword単位XOR観測が更新前stateに依存するというrank条件を検査する。これは「線形観測で最初の既知値を抽出できない」という限定した保証で、一般的な解析耐性ではない。可能ならbit単位の線形観測にも拡張して検査する。

## 意味保存・範囲

AND/XOR/OR/定数rotateからなるi32式、private scratch、固定回数、trapなし。整数の各bitの値とbit間のrotateを保持する。H^D=E F^D E^-1なので、Eが全単射で出力を変えなければ正答。資源不足と一般のmemory/CFG/importは対象外。Wasmの限定したbinaryを変換する。

## 想定解除と選定基準

1. 線形な観測を探し、入力だけで決まる座標を順に回復する。
2. 二次以下の観測まで持ち上げ、観測のpullbackを既知観測の演算で表せるか線形代数で調べる。元の逆変換が低次数なら、この拡張で復元できる可能性がある。
3. 必要に応じて入出力学習・固定回数unrollとも比較する。小さい入力族だけの失敗を全関数へ一般化しない。

追加解析費用と追加実行費用を同じ対照に対して比較する。上限到達・未対応・クラッシュは別扱い。線形rank条件を満たしても、二次観測で安く回復できる場合は強い主張をしない。高次数の逆変換を単に増やす改変だけを別発明と数えない。
