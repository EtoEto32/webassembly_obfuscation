# 逆元を使わない内部状態の消去

## 対象、差分、保護目標

前回の実装依存maskは、元から存在しない補助状態を追加していた。今回は元の状態変数yを消し、出力xの履歴を保持する。これはアルゴリズム構成上の違いであり、学術的新規性の確認を意味しない。非線形系の入出力実現が最も近い一般原理。[文献記録](prior-art.md)参照。

R=Z/(2^32)上で、入力byte uを読み、次を同時更新するscanが対象。

```
x' = P(x,u) + b*y
y' = Q(x,u) + R(x,u)*y
return x after n input bytes
```

ここで式名Rと環Rは文脈で区別する。実装のP/Q/Rは基底 `[1,x,u,x²,xu,u²]` の6係数で表す。初期値x0/y0とbもプログラムの一部。bが偶数でもよい。公開ABIは`run(p,n)->i32`と1ページの非shared memory。係数は追加のprivate memoryに格納し、実際の計算で読み出す。係数領域をexportしない。プログラムの任意の副作用・制御を扱う変換器ではなく、全moduleを照合する限定profileである。

攻撃者にはバイナリ・方式・公開実行手段を与える。元ソース、係数manifest、生成時の対応表は渡さない。原状態yの一意な同定と、同じABIで動く短い等価実装の回復を区別する。後者を主保護目標とする。

## 変換

前回の入力をv、前回と今回の出力をa,cとすると、`c=P(a,v)+b*y_previous`。次の出力は

```
next = P(c,u) + D(a,v) + R(a,v)*(c-P(a,v))
D = b*Q
```

となる。データ部にはx0、w0=b*y0、P、D、Rだけを格納する。元のb/y0/Qを復号用に残さない。

```
if n == 0: return x0
v = load8(p)
a = x0
c = P(a,v)+w0
for i = 1 .. n-1:
    u = load8(p+i)
    next = P(c,u)+D(a,v)+R(a,v)*(c-P(a,v))
    a,c,v = c,next,u
return c
```

Pの二重評価が実行コストの主な追加要因。初期1byteの特別処理と過去の入力の保持も必要になる。

## 意味保存

`b*y_next = b*Q(a,v)+R(a,v)*(b*y_previous)`は分配法則で成立する。`b*y_previous=c-P(a,v)`を代入するので、bの逆元やyの一意性を必要としない。初期状態と更新の帰納法で出力関係を示せる。

public loadは元と同じ順序・同じunsigned addressで実行する。n=0ではpublic loadを実行しない。計算はi32 add/sub/mulだけであり算術trapを追加しない。private係数loadは固定の有効範囲内。public memoryを書き換えないため、通常終了時だけでなくtrap時の公開memoryも同じ。resource exhaustion、所要時間、engine内部状態までの同値性ではない。実装全体の機械証明はしておらず、テスト通過と代数の説明を分ける。

対象外：yを返す・外部へ書く、yの二乗等を更新へ使う、ホストcallback、shared memory、外部から変更できる係数、別のload順序、一般の関数・ループ。完全profileの再構築照合で拒否する。

## 非単射でも短い状態を作れる

攻撃者はyを求める必要がなく、w=b*yと置けばよい。

```
x=x0; w=w0
for each u in original load order:
    nx = P(x,u)+w
    nw = D(x,u)+R(x,u)*w
    x,w = nx,nw
return x
```

これは元と同じ2状態の短い実現であり、更新ごとに過去のPを再計算しない。回復器は実行に使う係数dataをバイナリから読み、history profileのraw/O3と一致するかを全moduleで検査した後、このコードを生成する。一般のWasmから非線形実現を推定する攻撃とは主張しない。

b=2^r*q（qは奇数）なら、y→b*yのkernelは2^r個ある。y0またはQの係数へkernel要素を加えても、出力xを変えない元プログラムを作れる。b=2^31では2^31個のyが同じwへ写る。しかし、その非一意性が上記の短い実現を妨げることはない。ここがこの案の具体的な失敗原因である。

## 判断

回復成功だけで棄却するのではない。実測ではhistory側の実行・サイズが増え、方式既知の同じ抽出器から安くquotient側へ戻る。原理的にも一般の状態消去・実現理論から独立した新規性を確認できない。この限定案を主発明にせず、未確認の特許性を主張しない。
